Official Description

NVD Source Risk Analysis
The Danfoss legacy AK-SC 355 and AK-SM 800 Series shipped with default credentials that are written in the product manual, so anyone who knows or looks up those passwords can log in without authorization. The CVSS score of 9.9 (Critical) reflects that an attacker needs no prior privileges or user interaction and could gain high impact on confidentiality, integrity and availability. No EPSS score is available, so exploitation likelihood cannot be judged from that metric. The description states all versions are affected.
No public exploit is known (exploit_status is none) and the CVE is not in CISA's KEV catalog. The vector (AV:N, AC:L, no privileges required) indicates it is remotely exploitable with low complexity, and because the default credentials are publicly documented, little skill would be needed if a device is reachable.
Recommended Action
No product or fixed-version list is provided, so check with Danfoss for updated guidance, and change all default and known passwords on every affected unit immediately. Keep these devices off the internet, place them behind a firewall or segmented network, and restrict management access to trusted hosts or VPN.
