German software giant SAP discloses a cybersecurity incident

German software vendor SAP on Thursday confirmed a cybersecurity incident in which attackers reportedly stole employees’ authentication tokens to access source code stored in a GitHub platform.

In a letter sent to its employees, seen by the German Press Agency, the company urged employees to review their systems and determine whether they need to change their access.

“According to the current state of our investigation, we have found no evidence of unauthorized access to customer business data,” SAP told the German Press Agency (dpa) . The company further added the compromise stemmed from its GitHub platform for developer productivity and software provision.

Citing unidentified sources within the company, Der Spiegel reported that hackers stole SAP employees’ authentication tokens, which allowed them to access and copy source code stored within the compromised GitHub repository.

The Walldorf-based German company is a leading multinational enterprise resource planning software vendor used to manage core business operations such as sales, inventory and HR.

“We are dealing with tools that enable cyberattacks in previously unknown quantities and speeds,” BSI President Claudia Plattner told German news outlet Handelsblatt. “Cyberaggression has changed – it has not only become faster, more comprehensive and more powerful, but also many times more complex.”

SAP has restricted access to GitHub, halted automated processes in software development and replaced its signature keys. Additionally, it has provided its employees with an internal testing tool to detect any malicious code. The company also requires developers to now cryptographically sign every piece of code, Handelsblatt added.

SAP did not immediately respond to a request for comment.
