DSA-2026-12-01
CVE-2026-129713

Stack-based buffer overflow in Danfoss AK-SM 8xxA unauthenticated CGI handler
Danfoss AK-SM 8xxA - version 5.4.0 and earlier

Remediations:
This vulnerability will be addressed in Danfoss AK-SM 8xxA Series upcoming software version 5.5.x.

Further, we will remove the option that customers can disable the product Strict mode.

Mitigations:
Follow the instructions provided in the product’s manual, avoiding Internet exposure of all units on public IP

Make sure remote access to the units is possible only through a secure VPN or in general over a protected network

Configure the units to Strict mode, which ensures higher security levels on the product

Recommend using strong passwords

CVE-2026-127057

Exploitation of Weak or Known Passwords in Danfoss AK-SC 355 and AK-SM 800 Series

Danfoss legacy AK-SC 355 - all versions

Danfoss legacy AK-SM 800 - all versions

Remediations:
Install according to the instructions of the manual, avoiding public IP exposure;

Update the fleet (AK-SC355, AK-SM800) to current generation products (AK-SM800A series), to ensure receiving continuous cybersecurity updates.

Mitigations:
Remove internet exposure of affected units and of all units exposed on public IP

Re-establish access to the units only through a secure VPN or in general over a protected network

Recommend using strong and unique passwords
