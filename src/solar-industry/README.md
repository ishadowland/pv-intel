## 采集口径

本域只收**会传导到产品或经营决策**的信息。判断标准是下面这条链能不能走通：

```
外部变化 → 影响我方某个具体指标 → 需要改产品行为？
```

走不通的一律不进本域（只进简报的"背景噪声"区）。

### 四条采集线

| 采集线 | 看什么 | 为什么重要 |
|---|---|---|
| **价格曲线** | 硅料 / 硅片 / 电池片 / 组件 价格与价差 | 组件价直接进电站资产估值模型与发电量结算成本 |
| **供需与产能** | 排产、开工率、库存、产能置换 | 判断价格拐点，决定要不要提前锁组件 |
| **技术与路线** | TOPCon / HJT / BC 迭代，储能配比，构网型 | 影响我方电站数据模型字段（设备型号、效率、构网标识） |
| **装机与出口** | 国内新增装机、出口量、海外准入 | 决定市场增量落在哪，牵引产品功能优先级 |

### 重点跟踪对象

我方托管的电站资产涉及的技术与业务对象：

- 组件：单晶硅 / TOPCon / HJT，逆变器品牌与型号
- 电站类型：集中式 / 分布式（工商业、户用）/ 农光 / 渔光
- 业务系统：品能者托管、兆瓦快链、PTM 现货交易平台、idmo

### 采集频率

| 粒度 | 频率 | 产物 |
|---|---|---|
| 价格曲线 | 每周 | 价格快照 + 价差变化 |
| 供需与产能 | 每两周 | 供需平衡表 |
| 技术与路线 | 每月 | 路线图对比 |
| 装机与出口 | 每月 | 数据更新 |

### 每篇产业文档的落库格式

**统一用 [七段式文章结构](../meta/pipeline.md)**，产业域额外要求：

- 第 1 段信源核实：价格数据**必须标明报价机构**（InfoLink / SMM / Mysteel / 集邦），不同机构口径不同
- 第 2 段事实核查：**同一环节多机构数字常打架**（如硅料 32.5 vs 40.2 元/kg），必须核清差异来源（口径不同 / 采样日不同），**不要挑一个顺眼的用**
- 第 3 段快照：抓**数据源页面**（如集邦现货价格页），并在文中标注报价日期
- 第 5 段「我方判断」要区分**价格事实**与**拐点判断**（"在底部"是判断，不是事实）
