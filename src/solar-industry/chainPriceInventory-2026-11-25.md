- ⚠️ **库存与产量两处三源分歧**：库存 集邦 57 万吨 / SMM 41.1 万吨 / 库内 11-18 的 SMM 38.5 万吨；产量 集邦 9.5 万吨 / Mysteel 8.22 万吨 / SMM 周度折算 ≈8.2 万吨（**SMM 与 Mysteel 高度吻合、集邦偏高 15.6%**）→ 均未闭环，**不得用它们推导去库速度**。

## 五、主要观点

**原文主张**

- Mysteel（盘面数据，无文字判断）：11-25 多晶硅主力收 31385（−1.88%），持仓 +3,146 手，仓单 14,970 手，成交量 +35.53%；工业硅主力收 8260（−0.12%），仓单 −1,715 手。
- 华泰期货（策略观点）：「**需求端持续乏力导致的库存积压始终是多晶硅价格难以上涨的核心因素**……短期内关注减产执行力度、现货报价与成交能否跟随、以及产业链库存去化情况；中长期仍要回到**能耗新标对产能出清的效果**与供需格局的演变」「单边：短期区间操作，主力合约短期预计持续震荡」。
- 硅业分会 / 安泰科（周评）：现货成交延续清淡，仅个别企业达成少量交易；四条成因（库存高、去化缓 / 需求偏弱 / 硅片下行仅刚性补库 / **期货盘面走弱压制现货**）；「整体来看，各企业生产调整持续推进，供给端收缩延续，但**行业库存仍处高位、去化进度偏缓**，下游亏损与需求偏弱仍对现货成交形成制约」；10 月净出口延续且进口回落。
- 集邦（价格表说明）：「当前多晶硅库存维持在 57 万吨以上，供需过剩压力依然较大……预计全月国内硅料产量降至 9.5 万吨左右，但对比下游拉晶需求略微过剩，**累库趋势放缓**」。
- ⚠️ **已排除样本（2025-08-20 旧稿）**：「价格延续涨势的主因工信部等召开光伏产业座谈会，明确进一步规范光伏产业竞争秩序的决心，给市场释放了坚定『反内卷』积极信号」—— **本库不采信，但其中「反内卷信号 → 限产限销 → 囤货 → 买涨不买跌」的传导链，与本期硅业分会 11-25 说的「限产限销 + 需求偏弱」是同一套机制的两面，必须分开写。**

**我方判断**

- ⭐⭐⭐ **本期最有价值的不是新价格，是「持仓数据补齐 + 悬案结案」。** 库内 11-24 把「无持仓数据 → 价涨仓增是否延续无法判定 → 不得写多头进场延续」写成了当日第一价值点。**今天补上持仓，答案是 11-24 减仓（8.26 万 → 8.10 万）、11-25 增仓（+3,146 手）且价格跌 1.88%。** 这条链读下来是：**11-23 价涨仓增（+0.84%）→ 11-24 价涨仓减（+0.06%）→ 11-25 价跌仓增（−1.88%）** —— **三步就把库内 11-19 记的「期货 2701 四连跌、空头主动加仓」模式完整接回来了，而中间那天因为缺数据我们什么都不敢写。** → **动作不是「本期判断」，而是把「期货持仓 + 仓单 + 成交量必须逐日登记」写进价格表的强制字段**（库内 11-24 已提过一次，本期证明它不是可选项）。
- ⭐⭐⭐ **「双轨」这件事从「冲突」升级为「结构」，处理方式必须从「消歧」改为「登记」。** 集邦 33.5 与百川 40.0 相差 19.4%，且**这个差值与库内 11-18 的 19% 几乎相同** → 这不是数据错误，是**两个机构在不同样本上定价**（集邦做的是「现货合约/订单成交价」，百川做的是「主流现货参考价」）。**正确做法是把它建成「曲线 A / 曲线 B」两条并列序列，各带适用场景说明，并规定我方默认用哪条（默认取百川/主流，与库内 11-19 已定的「加权成交价」方向一致；集邦那条用于观察「硅片—电池—组件」相对强弱，因为它是唯一给出全链规格涨跌幅的表）**，而不是继续把它们记成「冲突数 +1」。
- ⭐⭐⭐ **「期货压制现货」这条必须改写我方的价格基准表口径。** 库内 11-19 记的是「下游参考期货价补库 → 锚从现货切向期货」；本期硅业分会记的是「期货盘面走弱 → 期现报价相应走低 → 对现货成交形成压制」。**两条方向相反（一个是期货带涨现货，一个是期货压低现货），但共同说明一件事：期货已是现货的一阶影响因素，不是背景。** → 我方「加权成交价双轨」不能只做「现货 + 期货折算」的静态加权，**必须显式登记「期货变动方向」并把它作为现货报价的先行项**，否则我方基准表会在期货领跌时系统性偏慢。
- ⭐⭐ **进出口月度序列已经够我方建一个「海外回补监测」了。** 10 月进口环比 −19.9%、出口环比 −5.1% → **净出口扩大**。库内 11-18 的结论是「我国为净出口国 → 国内减产效果被海外回补抵消」；**本期把它从单月快照变成两个月趋势，且净出口在扩大 → 减产的价格效果正在被出口部分抵消**。→ **可执行动作：把「多晶硅月度进出口量 + 净出口 + 进口均价」建成月度序列并入库**，这是判断「减产是否真的在价格上见效」的一个外生校验项。
- ⭐⭐ **产能集中度 90.7% 这个数有政策含义，不只是产业含义。** 头部 7 家占 90.7% 产量、开工率 47%（中小档 68%）→ **限产限销只需少数几家执行就能改变全行业供给**，这正是「反内卷」在供给侧可执行的结构基础；同时 11 月行业开工率预计降到 **36%** → **减产执行力度正在加大**。→ **我方对上游成本与交付的判断，不能只看报价，要看「开工率」这个先行量**（库内 11-24 已记「减产可逆，须建计划检修/实际检修/兑现率逐月核台账」；**开工率就是那个兑现率的代理指标，且已可直接观测**）。
- ⭐⭐ **SMM 周度折算 ≈ 8.2 万吨/月与 Mysteel 8.22 万吨几乎完全吻合，是库内第一次出现两个不同机构在同一量级互相印证。** 这比任何单个价格数字都更有用 —— 它说明**「周度产量 → 月度产量」的折算可以作为交叉校验器**，我方可用它来筛掉集邦那类明显偏离的预测（9.5 万吨）。→ **动作：给「产量预测」这类前瞻数配一条「至少两个独立源落在 ±10% 内才采信」的校验规则。**
- ⭐ **时间戳陷阱必须立成规则，而不是靠人眼。** 本期抓到的是一个**页面显示「最后更新 2026/11/25 11:30」但内容是 2025-08-20 旧稿**的样本 —— 而且**搜索引擎还把它排在最前面**（我方第一轮检索就是命中它）。**如果只按检索摘要入库，会把 2025 年 8 月的价格当成 11 月的价格，误差 16 个月。** → **动作：价格类采集的校验项从「URL 可访问」升级为「正文时间锚与目标数据日期一致」**，且快照必须保留正文首段以便复核。**本期这条规则已经救了一次。**
- ⚠️ **组件零变动不是企稳。** 库内 11-24 已写「报价层价格发现已失效，成本基准只能取实际成交/中标口径」；集邦 11-25 的组件 0.70/0.72 三日不动，正是这个判断的继续成立。**不得写「组件价格企稳/止跌」** —— 唯一诚实的表述是「**组件报价层连续三日零变动，但报价层已失去价格发现功能，不构成需求回暖证据**」。
- ⚠️ **库存与产量口径未闭环，不得用于推导。** 库存三源 57 / 41.1 / 38.5 万吨（其中 SMM 自身跨期差 2.6 万吨，说明是期次或口径不同）、产量三源 9.5 / 8.22 / ≈8.2 万吨。**「累库趋势放缓」是集邦一家的定性，不是我方的结论。**
- ⚠️ **硅料周成交价同一份转载快照内部就有两套数（4.30/4.03 vs 4.72/4.43）** → 只能并列登记为「棒状硅口径 / 区间均价口径」，**不取其一、不取均值**。这条也说明**转载型快照的正文可能是多期拼接**，采集时应优先取原发方。

## 七、总结输出

**一句话结论**：11-25 光伏主链的真正增量不是价格本身，而是**库内第一次拿到多晶硅期货的完整持仓 / 仓单 / 成交量三元组，并因此把 11-24 挂出的悬案结案 —— 11-24 是「价涨仓减」（8.26 万 → 8.10 万）、11-25 是「价跌仓增」（+3,146 手至 84,181 手、收 31385 / −1.88%），即库内 11-19 的空头加仓模式在中断两日后重现**；同期拿到 **10 月多晶硅进出口量与均价序列**（净出口扩大到 1,323.4 吨，**部分闭环 11-18 的进口均价量纲异常待核项**）、**产能集中度首次可量化**（头部 7 家占 90.7%、11 月开工率降至 36%）、以及**硅料现货「集邦 33.5 vs 百川 40.0」的稳定双轨**（差 19.4%，与 11-18 的 19% 几乎相同 → 是两条曲线不是一条错数）；同时本期抓到**一条「页面标 2026/11/25 实为 2025-08-20 旧稿」的时间戳陷阱样本并已排除**。
