## 五、主要观点

**原文主张**

- 集邦：硅片、电池片价格继续下探，组件市场高低效产品表现分化；多晶硅"整体价格有**明稳暗降**的风险"；政策层面反内卷预期增强、企业成本管控意识提升，**行业稳价意愿有所增强**。
- SMM：多晶硅减产力度可能不及预期（12 月部分厂家推迟原定检修），硅片"弱成本侧预期拖累价格"；电池 210R 下调至 0.296-0.305 且厂商预期向 0.29 收敛；组件"**高低效产品的价差持续扩大**"、库存结束四周去库；玻璃"报价维持高位部分源于**行业联合挺价**、供给端未实质缩减"。
- 华泰期货：需求端持续乏力导致的库存积压始终是多晶硅价格难以上涨的核心因素，短期内关注减产执行力度、现货报价与成交能否跟随、产业链库存去化。
- 北方有色：盘面重心下移较多、远月跌得更深，资金对供需态度已偏向悲观；主力换月后交易逻辑基本从政策与减产预期**转向弱现实**；行业协同减产确实让当月理论供需好了一些，但上下游积压的库存没见实质去化。

**我方判断**

- ⭐⭐⭐ **本期最硬的一条不是价格，是"证伪"**：库内 11-18 的"41.35 持平"用本期自洽等式即可反推为错值，**三期链因此首次自洽**。⭐ **这暴露了一个方法论问题 —— 库内连续三期照抄同一来源的"较昨日变化"字段而未做链式自洽检查**，导致一个错值在库内存了两期。**建议把"自洽链校验"固化为价格表入库的强制步骤**（同一来源连续三期的 A − Δ = B 必须成立，否则至少一期作废）。
- ⭐⭐ **"下跌 + 增仓"持续两日，比价格本身更值得记**。库内 11-18 已把"下跌伴随增仓 = 空头加仓"作为判断依据，本期该信号**继续成立并放大**（两日 +13.5%）。⭐⭐ **对我方的直接含义**：**组件采购若考虑期货锁价，当前是持仓结构最不利的时点**（空头主动建仓意味着远月贴水扩大）→ **采购策略应优先走长单/点价，期货只做短期扰动对冲**（与库内 11-18 记的"期货单日开仓上限 200 手 ≈ 1000 吨/日、不能替代长单"一致）。
- ⭐⭐ **集邦那句"下游转而参考期货商价格补库"是本期最有价值的行为学变化**，它比任何价格数字都更接近"价格发现机制在换锚"：**当采购方开始拿期货价当现货谈判的锚，现货挂牌价的信息价值会进一步下降** → **我方价格基准表必须从"挂牌价"转向"加权成交价（现货 + 期货折算）"双轨**，否则我方算出来的项目收益会系统性偏离市场。
- ⭐⭐ **玻璃这条必须和库内 11-17 的结论并排读**：库内 11-17 记的"价格天花板约 13 元/㎡、二三线即复产"是**价格行为的结果**；SMM 本期明确指出**成因是协同挺价 + 供给未实质缩减**，且**9 家具名厂报价完全统一 11.5 元/㎡**（无一家低于此价）→ **"价格不跌"不等于"供需改善"**。⚠️ **对我方的采购含义**：**玻璃成本地板不可按当前价位外推长期**（协同一旦松动，价格弹性可能很大），**组件成本模型里玻璃项必须做"挺价破裂"情景压力测试**。
- ⭐ **组件成品库存止跌回升这一条，虽只有一周，但方向反直觉且重要**：报价持平 + 库存回升 = **供给收缩慢于需求收缩**，而不是需求好转。⭐ **对我方客户侧的含义**：**分布式/集中式项目在年末的组件议价空间会扩大**，且**四季度末至春节前的交付窗口会前移到 11 月内**（与库内 11-17 记的"海外政策窗口期收尾"同向）。
- ⭐ **"减产力度不及预期"（12 月检修取消）是可逆的**，它对库内 11-16"减产在跑"的判断是**重要修正** → **"减产"必须建成一个逐月核的动态台账字段（计划检修 / 实际检修 / 兑现率），而不是一次性写成"已减产 X 万吨"的存量事实**。
- ⚠️ **同期三项判断不能下**：**不得写"多晶硅价格连续下跌"**（11-17→11-18 持平）、**不得写"硅片跌"也不得写"硅片平"**（集邦 vs SMM 单点表冲突，且 SMM 自身正文与表冲突）、**不得写"组件需求好转"**（库存回升是需求转弱的镜像）。

## 七、总结输出

**一句话结论**：**11-19 主链的真正变化不在价格，在"证据结构"—— 期货主力 2701 四连跌至 32260（-2.23%）、四日累计 -4.05% 且持仓两日累计 +13.5%（空头主动加仓），而复投料 41.04 的自洽等式（41.04 + 0.06 = 41.10）直接证伪了库内 11-18 记录的"41.35 持平"（三期链首次自洽为 41.10 → 41.10 → 41.04，41.35 是错值）；同时 SMM 硅片库存/产量在本期换期（26.74 → 27.23GW、12.71 → 12.75GW，多晶硅侧未换），推翻库内 11-18"四数连续两日一字不差 = 周频同一期"的判定；⭐⭐ 本期还首次入库了四个新口径 —— 硅片**区间价**（0.88-0.899 / 0.947-0.983 / 1.078-1.094）、组件**成品库存**（结束连续四周去库、回升至 24-25GW，即"报价持平但需求在转弱"）、组件**高低效分档价**（210R 高功率 0.756 连涨两周、BC-210R 0.7625）、玻璃**逐厂报价与联合挺价成因**（9 家具名厂 2.0mm 单镀面板统一 11.5 元/㎡含税、产能利用率 50%~100% 分化、SMM 明言"供给端未出现实质性有效缩减"）；⭐⭐ 两条最可执行的行为学结论是 **"下游转而参考期货商价格补库"（价格锚正在从现货切向期货 → 我方基准表必须双轨）** 与 **"12 月部分厂家取消检修、减产力度不及预期"（减产可逆且被资金压力反向抵消 → 减产必须逐月核、不得写成存量事实）**；⚠️ **四条不可下的判断**：**不得写"多晶硅连续下跌"**（11-17→11-18 持平）、**不得写"硅片跌"或"硅片平"**（集邦续跌 vs SMM 单点表标持平，而 SMM 自身周评正文又定性为下跌）、**不得写"组件需求好转"**（库存回升是需求转弱的镜像）、**不得把玻璃"价格不跌"读作"供需改善"**（成因是协同挺价）；⚠️ **库内 11-18 的复投料 41.35 须正式作废并改记 41.10**。
