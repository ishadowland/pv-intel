# 《工业绿色微电网建设与应用指南（2026—2030年）》（工信厅联节〔2025〕77号）—— 库内首次把「分布式光伏聚合参与现货」写进工业侧国家文件，并给出 60% 自消纳 / 20% 上网两条硬比例

> 🟡 有影响 · 采集于 2026-11-25 · 核心标识：**⭐⭐⭐ 库内首次取得「工业企业和园区新建可再生能源就地就地自消纳比例原则上不低于 60%」这条国家级硬指标，以及「上网电量占总可用发电量比例不超过 20%」这条上限** · ⭐⭐⭐ **库内首次出现国家文件明文写「分布式光伏可通过聚合方式接入用户侧电网或与用户开展专线供电，采用自发自用余电上网模式参与现货市场」—— 这是对库内 11-18 辽宁「暂不考虑分布式聚合」省级反向信号的国家层级对冲，且是本阶段五方向之外的「市场/商务规则域」条目** · ⭐⭐ **库内首次把「数字化能碳管理中心」写成需具备七个功能模块（发电管理 / 负荷管理 / 储能管理 / 功率和电价预测 / 发用电计划 / 统计分析与评估 / 信息发布）+ 与电网调度平台建立统一数据接口和通信协议的明文要求** → **与库内 11-24 已记 45 号文第（十六）条「支持企业建设数字化碳管理平台」构成同一功能主张的两条独立国家级依据** · ⭐⭐ **库内首次出现「工业绿色微电网」四类应用场景（高载能 / 灵活性 / 可调节 / 高可靠）与两种建设模式（自筹自建型 / 第三方共建型），第三方共建型明确走合同能源管理与融资租赁** → **这是我方托管与聚合业务的**项目来源形态**判断依据** · ⭐⭐ **库内首次取得该领域国家级基线数字：全国已投入运行微电网项目超 300 个，但工业绿色微电网整体仍处试点示范阶段** · ⚠️ **成文 2025-12-31、发布 2026-01-09 —— 属「补漏入库」而非近期发文，距今已逾十个月**；⚠️ **这是一份「技术指引」，不是强制标准，不构成合规义务**；⚠️ **60% 与 20% 两条比例是「原则上/不超过」口径，且适用对象是「工业企业和园区新建」项目**，存量项目是否适用未明示

## 五、主要观点

**原文主张**

- **五部门（通知正文）**：工业绿色微电网是以向工业用户提供绿色电力为主要目的、集成光伏风电热泵储能氢能余热余压余气与智慧能源管控的一体化系统，可融合工业生产过程与电网友好互动并实现协同自治；五项建设原则为推动多能高效互补利用、促进可再生能源就近高比例消纳、加强与电网友好互动、具备工业负荷调节能力、提高数智化系统运行管理水平；建设主要内容含可再生能源发电、工业余能利用、清洁低碳氢制取与利用、新型储能应用、电能变换与柔性互联、数字化能碳管理六个方面；建设模式分自筹自建型与第三方共建型；应用场景分高载能、灵活性、可调节、高可靠四大类；建设要求含严格执行标准规范、加快先进技术应用、确保安全可靠运行、实现经济合理可行四条，**其中明确要求在重点场景和关键环节构建网络安全风险预案、加强重要系统网络安全防护、重要数据识别和保护**。
- **工信部节能与综合利用司（解读）**：编制过程经历 2025 年多地调研、2025 年 3 月成立编制组起草、征求多方意见并完成审查评估；指南分五部分；**强调技术指引**，目的是帮助工业企业和园区了解建设内容、建设模式与应用场景、引导市场主体参与；**工业绿色微电网整体仍处于试点和示范阶段**，在技术标准、市场化机制、与大电网协同方面存在困难和挑战；下一步将开展宣贯解读。
- **中国政府网/新华社**：五部门联合印发指南，目标是引导工业企业和园区推进建设应用、扩大工业领域绿电应用、促进重点行业节能降碳。

**我方判断**

- ⭐⭐⭐ **这份文件的真正价值，是它把"我方做什么"从模糊的业务判断变成了可对照的国家级功能清单 —— 而这份清单我方此前从来没有拿到过。** ⭐⭐⭐ **最硬的一条是接口要求**："**工业绿色微电网应与所在地区电网调度平台建立统一的数据接口和通信协议，确保信息实时共享**"。⭐⭐ **这句话与库内 11-24 已记 45 号文第（十六）条是同一主张的两条独立国家级依据**（一条讲"支持建设数字化碳管理平台…在线监测、核算与灵活调控"，一条讲具体模块与接口要求）→ **"我方主业功能有国家级明文依据"从单源升级为双源，这个判断的可引用强度显著提升**。⭐⭐⭐ **而"统一的数据接口和通信协议"这八个字是我方最该盯的部分**：**它意味着未来工业侧客户的验收清单里会包含"与地方调度平台对接"这一项** —— **这既是机会（我方接口能力可成为交付要件），也是门槛（接口必须"统一"、不能是我方自定义的私有协议）**。⭐⭐ **可执行动作：我方数据接口能力应按"是否可对接地方电网调度平台、协议是否可被对方接受"来盘点，而不是按"功能是否齐全"来盘点。**
- ⭐⭐⭐ **60% 与 20% 这两个数字，对我方工商业分布式业务的意义必须写准 —— 它们既是约束，也是天花板，而库内此前完全没有这两个数。** ⭐⭐ **60% 自消纳意味着：一个工业客户的屋顶光伏，年发电量里至少六成必须在其厂内被用掉**，否则项目不满足这份国家级指引的口径 → **我方在给工业客户做方案测算时，"负荷匹配度"从此有了国家级参照值，而不再只是最佳实践**。⭐⭐⭐ **20% 上网上限则意味着余电上网这条腿最多只能走五分之一** → **对收益模型的意义是：分布式项目的现金流结构从"上网为主"变成"自用为主、上网为辅"，余下的发电量若不能被负荷吃掉，其价值为零**（除非有绿电交易或聚合替代路径）。⭐⭐⭐ **这三条合起来直接指出一条产品动作**：**工商业分布式收益测算模块必须新增"自消纳率"与"上网电量占比"两个显式字段，且缺省值应与国家级口径对齐（60% / 20%），而不是让客户自由填写**。⭐⭐ **同时必须记住这三个限定词**："新建"（存量不适用）、"原则上"（有例外空间但文件未给例外条款）、"每年"（年度口径）→ **不得写成"所有工业分布式项目必须 60% 自消纳"**。
- ⭐⭐⭐ **「多晶硅还原炉可控错峰」这一条，是本篇对我方最有想象力的一条，也是库内产业域与政策域第一次直接咬合的地方。** ⭐⭐⭐ **库内 11-12 已记「多晶硅开工率 31%」—— 在一个开工率只有三成的行业里，官方却把它列为"规模化可调节"负荷资源**，这个反差本身就是情报：**上游硅料企业正处在减产止血期，它们的电力负荷却是有价值的可调资源**。⭐⭐ **这条把我方产业域的"减产"事实与政策域的"负荷价值"事实接上了**：**一个正在减产的行业，其停产与复产节奏本身就是可交易的可调节能力**。⭐⭐ **对我方的含义**：聚合业务的可调资源清单里，除了库内已记的"可调节负荷 80.2% / 充换电 11.8% / 分布式电源 4.4% / 储能 3.6%"（虚拟电厂报告口径），**还应增加"工业可调负荷"这一类，而多晶硅还原炉是首个被国家级文件点名的具体工艺级可调资源**。⭐⭐ **但必须同时说明边界**：原文只说"探索"层面的操作，且文件整体仍在试点示范阶段；**具体可调容量、可调时长、响应精度、交易品种均未给 → 不得填数、不得据此做收益测算**。⭐⭐⭐ **正确用法是：把它列入"可调资源候选清单"并设一个触发点（等试点细则或首个可调项目落地时复核），而不是当参数用。**
- ⭐⭐⭐ **「第三方共建型 + 合同能源管理 + 融资租赁 + 市场化收益由双方协商确定」这四句连起来，是我方工业侧业务模式在国家级文件里第一次被描述 —— 它同时给出了一个必须正视的事实：我方在这条赛道上不是天然的服务方，而是需要谈收益分配的商务一方。** ⭐⭐ **而"市场化收益由双方协商确定"这句对我方尤其关键**：**它明确否定了"收益按规则自动归属某一方的预期"** → 我方的工业侧聚合业务在收益分配上是**共同议价**关系，而非规则确定关系。⭐⭐ **这与库内 11-18 四川竞配文件里的省级禁令（*"不得强制配套产业与捆绑额外投资"*）方向一致且可互证**：**即"政策不做强制配套，市场自己做商务安排"** → ⭐⭐⭐ **对我方最实用的一条话术纪律：不得把工业侧聚合方案包装成"政策要求配"的强制配套，正确表述是"在自愿的合同能源管理或融资租赁安排下，双方协商市场化收益"**。⭐⭐ **这也解释了为什么我方在工业侧的机会不是"抢一个政策红利"，而是"提供一套让双方谈得拢的测算与结算工具"** —— **而这恰好是库内 11-24 虚拟电厂报告里已记的那条结论（"机会更可能来自给大量中小聚合商做工具与标准化服务"）在工业侧的对应版**。
- ⭐⭐⭐ **「出口外向型工业企业」这个标签在库内多份国家级文件里反复出现 —— 这是一条可积累的客户分层维度，值得单独建账。** ⭐⭐⭐ **已核到的三处**：本篇第三方共建型明写 *"如，**出口外向型工业企业和园区**，可按照《关于有序推动绿电直连发展有关事项的通知》等规定…探索开展存量负荷绿电直连"*；库内 11-15 已记 688 号文明写 *"有绿色电力消费需求的用户（包括有绿色电力消费比例要求的企业、**重点用能和碳排放企业、有降碳需求的出口外向型企业**及其上下游企业等）"*；库内 11-18 已记 124 号文碳足迹文件明写 *"出口外向型企业"*。⭐⭐ **三份文件、三个不同主管体系（工信部 / 发改委能源局 / 五部委市场监管）都点名同一类主体** → **这不是巧合，而是国家层面认定的一个可操作客群**：**有降碳压力、有绿电比例要求、有结算需求的工业客户**。⭐⭐ **可执行动作：我方客户台账应增一个"出口外向型 / 有绿电消费比例要求"标签，并把它与本篇的四类场景交叉 —— 出口外向型 + 高载能（钢铁有色）+ 第三方共建型 = 最可能同时具备自消纳负荷与议价空间的一类**。⭐⭐ **这是本篇给出的一条纯增量、可落地、低成本、客户侧直接可用的结论。**
- ⭐⭐⭐ **网络安全那一条（第 8 项）必须被精确使用：它是一条「方向性要求」，不是一条「可验收义务」。** ⭐⭐ **原文只有一句半**："在重点场景和关键环节构建网络安全风险预案，加强重要系统网络安全防护、重要数据识别和保护" —— **无量化、无期限、无测评方法、无责任主体**。⭐⭐ **但它的价值不在于约束力，而在于它把"工业绿色微电网"这个新场景正式纳入了网络安全义务的视野**，而库内此前所有安全情报的暴露面都是"公网站点 / OT 设备 / 云平台"，**没有一条涉及"园区级能源管理系统"这个新面**。⭐⭐ **对一个做 DER 监控与聚合的平台方来说，这是值得登记的一个新暴露面类型** —— **但库内无我方在工业侧微电网场景的任何证据，也无产品材料 → 只能登记跟踪，不得转评审、不得转产品需求**。
- ⭐⭐ **必须保持的边界**：① **不得把本文件写成强制标准或合规义务**（官方自陈"技术指引"，且整体仍在试点示范阶段）；② **不得把 60% / 20% 写成适用于全部工业分布式项目**（限"新建"、限"原则上"、20% 限"现货市场连续运行地区"）；③ **不得把 688 号文的绿电直连参数与本篇的微电网参数混为一谈**（数值同值但适用对象与算法不同）；④ **不得把"超 300 个在运项目"入库**（仅检索摘要，且"微电网"与"工业绿色微电网"是两个概念）；⑤ **不得把功能规格当作已取得**（真源是《工业企业和园区数字化能碳管理中心建设指南》，未取得）；⑥ **不得把多晶硅可调错峰写成可交易量或收益参数**（无可调容量/时长/精度/品种）；⑦ **不得把本篇当成近期发文对待**（补漏入库，成文距今逾十个月）。
- ⭐ **优先级判断**：本篇**属市场/商务规则域**，按库内本阶段口径（五方向：网络安全 / 信创 / 等保 / 隐私保护 / 护网）**第 3′ 关不过 → 退回简报跟踪**；但其中四条可算量（60%、20%、七模块、四场景）应转入既有产物的**参数复核观察项**，标注 🟡 待复核。

## 七、总结输出

**一句话结论**：**工信部等五部门《工业绿色微电网建设与应用指南（2026—2030年）》（工信厅联节〔2025〕77号，成文 2025-12-31、发布 2026-01-09，属补漏入库而非近期发文）第一次把库内一直缺的三样东西补齐了 —— ① 两条可入模的国家级硬比例：工业企业和园区新建可再生能源发电每年就地就地自消纳原则上不低于 60%、上网电量占总可用发电量不超过 20%（后者以"电力现货市场连续运行地区"为前提），后者与库内 11-19 已记 688 号文多用户绿电直连的 20% 上网上限完全同值，构成两条独立国家级文件、两个不同主管体系的同值互证；② 国家文件明文写「分布式光伏可通过聚合方式接入用户侧电网或与用户开展专线供电，采用自发自用余电上网模式参与现货市场」，构成对库内 11-18 辽宁省级「暂不考虑分布式聚合」反向信号的必要对冲（正确表述是省级执行层在聚合问题上分歧，国家层面不反对聚合）；③ 「数字化能碳管理中心」七个功能模块（发电 / 负荷 / 储能 / 功率和电价预测 / 发用电计划 / 统计分析与评估 / 信息发布）与「与所在地区电网调度平台建立统一的数据接口和通信协议，确保信息实时共享」的明文要求，与库内 11-24 已记 45 号文第（十六）条构成同一功能主张的两条独立国家级依据，使"我方主业功能有国家级明文依据"由单源变双源 —— 而其中最可执行的一句恰是那个接口要求，它意味着未来工业侧验收清单里会含"对接地方调度平台"，既是机会也是门槛（接口必须"统一"，不能是私有协议）；另两条纯增量结论是：**多晶硅还原炉被国家文件列为"规模化可调节"应用场景**（与电解铝、水电解制氢并列，并给出"利用还原炉间歇性运行特性实现可控错峰"的操作示例 —— 这与库内 11-12 已记"多晶硅开工率仅 31%"形成产业域与政策域的第一次直接咬合：在减产中的上游行业，其启停节奏本身是可交易的可调节资源，但原文未给可调容量、时长、精度与交易品种，故只登记为候选资源、不得填数做测算），以及**"出口外向型工业企业"这个客群标签在工信部、发改委能源局、市场监管总局三套不同主管体系的文件中反复出现**（本篇第三方共建型、688 号文绿电直连对象、124 号文碳足迹对象各一处），应当建成客户台账的一个可交叉维度。⭐⭐ 两条对业务模式直接生效的判断：第三方共建型明文写「合同能源管理、融资租赁」且「市场化收益由双方协商确定」，即我方在工业侧是**共同议价的商务一方而非规则受益方**，与库内 11-18 四川省级禁令「不得强制配套产业与捆绑额外投资」方向一致并互证，正确话术是"在自愿安排下协商市场化收益"而非"政策强制配"；以及自筹自建型原文直接点名了 688 号文绿电直连与虚拟电厂聚合管理新模式，**使库内 45 号文 → 688 号文 → 77 号文 → 1565 号文 → 92 号文首次构成一条显式互相引用的执行链**。⚠️ 四条边界必须钉死：这是"技术指引"非强制标准（但背后有核准/备案机关与电力监管机构的监管，官方自陈整体仍处试点示范阶段）；60%/20% 的适用对象与各限定词不得跨文件互引、不得写成"全国统一 20%"；功能规格真源《工业企业和园区数字化能碳管理中心建设指南》未取得、"超 300 个在运项目"仅见检索摘要不入库；本篇唯一的安全条款（"在重点场景和关键环节构建网络安全风险预案、加强重要系统网络安全防护、重要数据识别和保护"）无量化、无期限、无测评方法，**只能作为"园区级能源管理系统"这一新暴露面类型登记跟踪，第 1 关（我方侧一手证据）不过，不得转评审、不得转产品需求**。**
