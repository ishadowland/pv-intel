## 四、概要提取

- **分布式、储能、虚拟电厂首次被明确列为可入市主体**，且可用"聚合、直接交易"两种模式 —— 我方虚拟电厂/储能聚合业务第一次有了政策入口
- **2026 年起新能源入市装机与发电量占比均超 80%**，新能源全面入市进入实操阶段
- 推广**多年期购电协议** + **缩短中长期交易周期**（合约持仓需支持频繁调整）
- **新型储能被纳入容量电价机制** → 储能收益来源从峰谷套利扩展到四类
- 重点大基地"沙戈荒""水风光"整体参与市场；分布式/储能探索聚合参与
- 有源配电网风控体系 + 新能源涉网安全管理制度 → 合规要求前移到产品
- 上位法《可再生能源法》修订草案 2026-11-02 首次审议（**尚未通过**）
- 多省收紧工商业分布式机制电价，工商业分布式告别"保底收益"

## 五、主要观点

**原文主张**

- 中国能源新闻网（官方解读口径）：新能源全面入市后，"将于市场设计带来诸多挑战"——随机性、间歇性、波动性、零边际成本、高系统成本；市场设计需应对
- 官方解读：**"聚合"是解决分散资源无法入市的机制路径** —— "填补规则空白，解决分散式资源无法入市难题"
- 官方解读：**大基地整体定价**，"鼓励新能源外送基地各类电源整体形成送电价格"，降低送受端协商难度
- 万劲松（能源局副局长）：方向是"扩量提质、可靠替代"，从"有没有"向"好不好"、从"补充能源"向"主体能源"转变
- 北极星/清华郭鸿业：机制电价退坡**不是简单减补贴**，而是"逐步厘清政策保障与市场交易之间的边界"；工商业分布式的竞争力将从"屋顶资源"转向"负荷管理、储能运营、电力交易、风险管理能力"

**我方判断**

- "研究推动跨省跨区直交易"是**趋势信号而非即刻义务** —— 用词是"研究"，我方改造应按**能力预留**（字段留 `ruleRef` 扩展位），而非按硬约束抢排期
- 多年期 PPA + 缩短交易周期**方向相反但目标一致**（既要长期锁定又要灵活调整）→ 我方合约模型必须同时支持长周期与高频调整，这是**结构性复杂度**，不是加字段能解决的
- 容量电价机制对我方是**净正面**：储能收益从"纯套利"变"套利+容量+辅助服务"，我方测算模型不升级就会**低估客户收益**，影响托管服务的定价说服力
- "涉网安全管理制度"是**最容易漏掉的一条** —— 它约束的是设备的可观测/可调/可控能力，属于产品字段而非后端逻辑
- 地方机制电价收紧对我方托管客户（工商业分布式）的**收益预期是负面**，会传导到续约意愿，需要产品侧准备收益解释能力
- ⚠️ 我方在该领域的定位是**托管与交易工具**，不是市场主体本身；政策红利最终落到"我方工具能否承接"，这决定改造优先级

## 七、总结输出

**一句话结论**：这份意见把**分布式、储能、虚拟电厂**从"被管理对象"变成"可入市主体"，我方工具若不能承接聚合交易、多年期合约与多元化储能收益，**在客户侧会直接失去定价说服力** —— 落地节奏取决于各省细则，因此**先做能力预留（数据结构可扩展），再按细则落地做功能实现**。

**落地去向**

- [x] 产品特性 —— 储能收益测算引擎升级为四段式（峰谷/现货/辅助服务/容量电价）
- [x] 需求变更 —— 交易合约结构扩展（多年期 / 跨省跨区 / 多品种 / 聚合模式）
- [ ] 产品特性 —— 分布式聚合调控申报通道（待各省细则明确后细化）
- [ ] 需求变更 —— 涉网性能字段新增（待"涉网安全管理制度"配套细则）
- [ ] 专项整改 —— 复核我方收益测算模型的现状精度基线
- [ ] 跟踪项 —— 136 号文文号待核；各省细则待发布；可再生能源法修订进展
