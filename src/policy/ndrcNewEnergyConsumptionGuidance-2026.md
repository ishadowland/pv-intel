# 发改委/能源局《关于促进新能源消纳和调控的指导意见》 — 解读

> 国家发展改革委 · 国家能源局 · 2026-11-10 发布 · 分类：🔴 **强约束**
> 对我方影响：结算与交易相关功能需跟进

## 一句话结论

**新能源全面入市进入实操阶段**（2026 年起入市装机占比、发电量占比均超 80%），**分布式、储能、虚拟电厂成为可参与市场的主体** —— 我方托管的分布式电站与储能聚合业务第一次有了明确的政策入口。

---

## 核心条款拆解

| 条款要点 | 原文表述 | 对我方的含义 | 需要做什么 |
|---|---|---|---|
| 主体参与市场 | "支持分布式新能源、储能、虚拟电厂等新型主体通过聚合、直接交易等模式参与电力市场" | 我方**虚拟电厂/储能聚合**业务从概念变为可交易主体 | 聚合交易的账户、报价、履约流程需产品化 |
| 跨省跨区直交易 | "研究推动新能源、用户等主体参与跨省跨区电力市场直接交易" | 交易范围可能跨省，结算规则复杂度上升 | 交易模块需支持跨省结算口径 |
| 多年期购电协议 | "通过推广多年期购电协议，帮助新能源企业锁定长期消纳水平、稳定项目收益预期" | PPA 签约成为常规业务场景 | 需支持多年期合约的收益曲线 |
| 交易周期缩短 | "缩短中长期市场交易周期，便于新能源合约持仓调整" | 持仓需支持频繁调整 | 持仓管理、敞口监控要更实时 |
| 现货与辅助服务 | "加快现货和辅助服务市场建设……激励发用两侧资源主动参与系统调节" | 储能收益来源从**单一峰谷套利**扩展到**辅助服务+现货价差** | 储能收益测算模型必须升级，否则给客户的预测失真 |
| 聚合调控 | 对"点多面广"小容量分布式新能源，鼓励探索聚合调控模式 | 分散资源需要聚合商代为申报 | 聚合调控接口/申报通道 |
| 涉网安全 | "建立有源配电网风控体系，完善新能源涉网安全管理制度" | 合规要求前移到产品 | 涉网性能数据需可观测、可上报 |
| 容量电价 | "健全完善煤电、抽水蓄能、新型储能等调节性资源容量电价机制" | 储能容量收益可预期 | 收益模型需加容量电价科目 |
| 分时电价传导 | "完善体现分时价值差异的零售市场价格机制，研究建立健全居民分时电价机制" | 自发自用价值测算口径变化 | 收益测算参数更新 |
| 电-证-碳协同 | "积极推动绿证市场高质量发展，推进'电—证—碳'市场协同" | 环境价值定价方式变化 | 绿证/碳资产数据需打通 |

## 影响面

**受影响产品线**：

| 产品线 | 影响点 |
|---|---|
| 兆瓦快链 | 聚合交易、持仓管理、现货敞口监控 |
| 品能者托管 | 分布式电站参与市场的申报通道、收益测算（含储能辅助服务） |
| PTM 现货交易平台 | 跨省跨区交易、多年期 PPA 合约模型、容量电价科目 |
| 品行者 | 涉网性能数据采集与上报 |

**受影响客户**：分布式业主（收益来源变化）、储能投资方（收益模型）、售电公司（交易能力要求）

**需要改的接口/字段**：

- 交易合约：新增合约期限（多年期）、跨省标识、辅助服务品种
- 储能收益测算：拆分为「峰谷价差套利 / 现货价差 / 辅助服务 / 容量电价」四段
- 电站资产：新增涉网性能指标字段（可观测率、调节能力标识）
- 绿证/碳：环境价值科目独立结算

|---|---|

| 2026-11-10 | 本意见发布 |
| 待定 | 各省细则落地节奏（决定我方改造排期） |

## 落地去向

- [x] **产品特性** —— 储能收益测算模型升级为四段式（含辅助服务与容量电价）
- [x] **产品特性** —— 分布式聚合调控申报通道
- [x] **需求变更** —— 交易合约数据结构扩展（多年期 / 跨省 / 辅助服务品种）
- [ ] 专项整改 —— 待我方现有收益测算模型的精度基线确认后再评估
