## 四、概要提取

- **立法进程**：11-02 提请十四届全国人大常委会第二十五次会议**初次审议** → **11-06 中国人大网公布全文、公开征求意见 30 日（截止 2026-12-05）**；提交通道为中国人大网 / 国家法律法规数据库 flk.npc.gov.cn / 邮寄全国人大常委会法制工作委员会
- **规模**：修订草案 **10 章 76 条**（现行法 **8 章 33 条**）→ **条文近乎翻倍**，2005 年施行、2009 年修正以来首次系统性重构
- ⭐ **删除"全额保障性收购制度"**（运行十七年），由三条制度承接：**① 市场定价**（入市电量电价由市场形成、未入市按国家价格政策）**② 可再生能源可持续发展价格结算机制**（依法保障合理收益；**每年新增纳入规模按国家下达的年度消纳责任权重完成情况等确定**）**③ 消纳责任权重 + 绿证履约**（设消费最低比重目标）
- ⭐ **消纳罚则**：地方逾期未完成 → 立即整改 + 上级政府可**约谈主要负责人**；**用能主体未达标 → 按缺口所需绿证费用的 5—10 倍罚款并记入信用记录**（库内首次）
- ⭐ **多元履约方式首次法律确认**：自发自用、绿电直连、绿证交易
- ⭐ **新型储能首次入法**：储能列为鼓励研发/示范/产业化关键技术领域；**容量电价机制 + 容量市场 + 电力容量保障机制 + 辅助服务市场 + 输配电定价机制**同时入法；**车网互动规模化应用 + 用户侧可调节负荷参与系统调节**；国务院能源主管部门制定**可靠容量评估技术规范**
- ⭐ **抽水蓄能首次入法**（据解读位于第 33 条"电力系统调节能力"清单，与光热、生物质、常规电源灵活性改造、新型储能、车网互动、用户侧可调节负荷并列）
- ⭐ **绿氢首次取得法律定义**（据解读：第 2 条适用、第 74 条定义、第 35 条管网公平无歧视接收、第 68 条罚则、第 51 条非电产品绿色能源证书制度）
- ⭐ **开发建设秩序**：不得将强制配套产业或投资作为项目开发建设条件；不得违规收取项目保证金；多主体申请同一项目许可须**竞争性配置**
- ⭐ **光伏侧利好两条**：**改造升级**受支持 + **达到设计使用年限的项目经评估后符合条件的可以继续运营**；省级能源主管部门须组织开展**分布式光伏接入电网承载力及提升措施评估**
- **委员建议（未通过）**：增设开发要素保障专门制度（用地规划衔接、负面清单+技术标准管控、优先利用采煤沉陷区/矿山废弃地）；第 54 条增加"国家支持提升太阳能等可再生能源转化效率的基础研究及技术创新"
- **配套制度坐标**：2026 年初 114 号文已建立电网侧独立新型储能容量电价机制（据解读，补偿区间约 **100—370 元/kW·年**，十余省份已落地）—— 本草案将其**从部门规范性文件上升为法定安排**

**原文主张**

- 中国人大网（官方）：修订草案 *"立足我国可再生能源发展现实，对规划布局、开发建设、输送消纳、产业促进、法律责任作出系统性制度安排，总体框架科学，制度导向清晰，为可再生能源高质量发展奠定良好法律基础。"*
- 煤炭资源网（解读）：*"**草案将容量电价写入，意味着这一政策工具将从部门规范性文件层面上升为法定制度安排**，储能收益预期所依赖的规则基础随之抬升。"*
- 网易号（转载整理）：*"运行了十七年的'全额保障性收购制度'被删除，同时用三条制度承接了原来的功能。"*
- CPEM（解读）：*"也正是在这份草案里，抽水蓄能首次被写入可再生能源法，却被置于'电力系统调节能力'条款。"*
- 国网辽宁电力发展部副主任郭尚民（关于机制电价的通俗解释，**见 [辽宁竞价文档](liaoningMechanismAuction2027-2026.md)**）：*"'机制价格'就是为给新建新能源项目一个相对稳定的电价预期。"*

**我方判断**

- ✅⭐ **这是本期层级最高的一条：库内所有政策条目（136 号文、消纳指导意见、1565 号储能方案、"十五五"规划、省级机制电价）第一次获得统一的上位法依据。** 具体对应关系是可指认的：库内的"**机制电价**"在草案里叫"**可再生能源可持续发展价格结算机制**"；库内的"**绿电绿证交易**"在草案里叫"**绿证是消纳责任权重的履约凭证**"；库内的"**配储自主决策**"在草案里对应"**不得强制配套产业或投资**"；库内的"**容量电价**"在草案里第一次成为法定安排。**这意味着我方此前分散在各文档里的政策口径，现在可以统一挂到一部法律下。**
- ⚠️ **但必须把三件事分开：草案 ≠ 通过 ≠ 生效。** 11-02 只是**初审**、11-06 才**全文公开征求意见**、截止 12-05。**入库的定性必须是"立法中"**，不能写成"新法出台"。库内 11-17 日报已把"可再生能源法修订草案"列为跟踪项，本期是**该跟踪项的第一次实质推进**（从"初审一句话"到"全文 + 具体条款 + 时限"）。
- ✅⭐ **对本阶段最有用的一条，是"绿证罚则 5—10 倍 + 记入信用记录"这一条。** 库内已记了绿证/绿电交易的产品方向（消纳指导意见的"电—证—碳"协同），但**一直缺一个"不用绿证会付出什么代价"的量化依据** → 现在有了：**用能主体未达最低消费比重目标，罚的是缺口对应绿证费用的 5—10 倍**。这把绿证从"可选的合规选项"变成"**有价格、有信用后果的刚性义务**" → **绿证需求的强制性显著高于库内此前的认知**。⚠️ 但要克制：**这是草案条文，不是现行义务**，写产品材料时必须标"立法中"。
- ⭐⭐ **对存量资产最有利的一条我方此前完全没有：*"并网运行达到设计使用年限的风电、光伏发电项目经评估后，符合条件的可以继续运营"* + *"支持符合条件的…改造升级"*。** 库内关于光伏的存量叙事一直偏向"利用率 93.1%、电价市场化、老电站收益承压"（见 [产能出清进度](../solar-industry/polyCapacityExitBiddingPrice-2026-11.md)），**却从未有任何一条官方文件说过"到期的项目不是自动废掉"**。这条若最终通过，**我方存量电站的"到期"这个隐含假设需要改** → 建议我方**在台账中把"是否达到设计使用年限"与"是否可评估续运"拆成两个字段**，避免把"到期"直接等同于"资产归零"。
- ⚠️ **"容量电价 + 容量市场 + 可靠容量评估技术规范"入法，对储能收益模型是结构性利好，但此刻不能改模型。** 库内已有 [《"十五五"新型储能实施方案》](storagePlan15thFiveth-2026.md) 与 [储能收益测算模型四段式](../deliverables/feature-storageRevenueModel-20261112.md) 产物。草案若通过，**"容量电价"将从可选项变成法定工具**（且草案要求国务院能源主管部门制定**可靠容量评估技术规范**，与"十五五"规划的**置信出力 8%** 指标呼应）→ **收益模型里"容量收入"这一段的假设强度应被显著加强**。⚠️ **但现在只是草案**，模型改造应标 🟡 待复核，**等出台后或征求意见反馈明确后再动**。
- ⚠️ **"暂不考虑分布式聚合"（辽宁）与本草案的"鼓励分布式就近开发、鼓励自用、余量上网"形成一组有意思的张力。** 草案层面给分布式**就近消纳**开了法律口子（自用、余量上网、绿电直连入法），但**省级竞价的执行层（辽宁）把聚合通道关掉了**。我方判断：**这两者不矛盾** —— 草案给的是"就近消纳/绿电直连"的路子，辽宁关的是"聚合后参与省级机制竞价"这一特定通道。**我方若把聚合作为分布式资产的主要变现路径，必须同时准备"聚合竞价"与"就近消纳/绿电直连"两条腿**，不能只押一条。
- ⚠️ **一个容易被忽略但很实的点：开发要素保障（土地）。** 委员建议提出"可再生能源开发用地实行规划衔接制度、推行负面清单加技术标准管控、优先利用采煤沉陷区/矿山废弃地"。这是**委员建议不是已通过内容**，但它指向一个我方此前完全没有触及的约束维度：**土地/用地合规**。分布式与集中式项目落地难，往往卡在用地而非接网 → **我方项目可行性评估清单应补"用地性质与合规"一项**（库内现有清单围绕接网、承载力、电价）。
- ✅ **"不得违规收取项目保证金"这条与我方业务模式直接相关。** 库内 11-13 记录过"项目保证金"作为合规风险点（新政前的地方实践）。草案把它写入法律 → **我方在承接政府/平台侧项目时若被要求缴纳项目保证金，这是一个可引用的拒绝依据**（须待生效后引用）。
- ⚠️ **时间约束提醒（唯一硬时限）**：征求意见 **2026-12-05 截止**。若我方对该草案有实质意见（例如对分布式聚合、绿证履约方式、储能市场主体地位的诉求），**这是一个有时限的公共参与窗口**（通过 flk.npc.gov.cn 或邮寄）。⚠️ 但**我方是否需要提交意见、以谁的名义提交，属于经营决策，不是本情报库的自动动作** → 本条仅记录窗口与渠道，**不代为提交、不起草意见**。

## 七、总结输出

**一句话结论**：**《可再生能源法（修订草案）》11-06 全文公布、征求意见至 12-05，是本期层级最高的一条 —— 它第一次为库内全部省级机制电价（广西 0.305 / 山西 / 辽宁 0.20）、绿证履约、配储自主决策、容量电价提供了统一的上位法依据（"可再生能源可持续发展价格结算机制"即我方"机制电价"的法定名称），同时带来四条库内首次内容：绿证罚则 5—10 倍 + 信用记录（绿证需求刚性化）、新型储能/容量电价/容量市场/车网互动/抽蓄/绿氢首次入法、存量到期项目"经评估可继续运营"（我方台账不得把"到期"等同于"归零"）、禁强制配套与禁保证金；⚠️ 但定性必须是"**立法中**"（11-02 初审 → 11-06 全文征求意见 → 12-05 截止），不得写成"新法已出台"；且抽蓄/绿氢的**条号与措辞为单源解读**、委员建议不等于已通过内容，须分别标注。**

**落地去向**

- [ ] **产品特性** —— 🟡 **待复核**：绿证/绿电交易产品定位表述补"立法中的 5—10 倍罚则与信用记录"依据（须标草案状态）；储能收益模型"容量收入"段假设强度标注为待加强
- [ ] **需求变更** —— 🟡 **待复核**：电站台账新增"是否达到设计使用年限 / 是否可评估续运"两字段；项目可行性评估清单新增"用地性质与合规"与"项目保证金合规性"两项
- [ ] **专项整改** —— ❌ **不勾**：政策/立法域，无我方侧暴露面证据
- [ ] **跟踪项** —— ① **2026-12-05 征求意见截止**（唯一硬时限；是否提交意见属经营决策，本库不代为提交）；② 抽水蓄能第 33 条、绿氢第 2/35/51/68/74 条的**条号与措辞二次核验**（当前单源）；③ "多元履约方式首次法律确认"的**官方原文核验**（当前单源）；④ 114 号文容量电价补偿区间 100—370 元/kW·年的**官方口径核验**（当前单源转述）；⑤ 立法后续（是否进入二审/表决）；⑥ 委员建议（土地要素保障、第 54 条太阳能效率条款）是否被吸纳
