# 省间省内绿电联合交易首次开市（2026-11-26）—— 绿电交易从「两级分别申报」并轨为「一次申报、联合交易」

> 🟡 有影响 · 采集于 2026-11-27 · 核心标识：**⭐⭐⭐ 库内首条「绿电交易机制并轨」事件** —— 11-26 国家电网召开西北—华东绿电联合交易启动会，**省间、省内两级绿电市场首次在同一套规则下实现「一次申报、联合交易」**，首单成交电量 **61.7 亿千瓦时**（其中西北跨区送华东 19.5 亿千瓦时）；⭐⭐⭐ **库内首份「绿电交易经营主体结构」的量化拆解** —— **1615 家**经营主体参与，其中 **427 家**售电公司与电力用户通过「一次报价、联合交易」匹配到来自 **1188 家**发电企业的绿电资源；⭐⭐⭐ **库内首条「绿电交易市场规模」的可引用基线**（61.7 亿千瓦时 / 十省区市）；⭐⭐⭐ **库内首条「国办发〔2026〕4 号在绿电品种上的首个落地样本」** —— 原文要求「跨省跨区和省内交易要由分别组织逐步转向联合交易」，本篇是该要求在**绿电**上的实际执行形态；⭐⭐ **库内首条「发电侧与购电侧收益逻辑变化」的官方表述**（「项目收益逻辑从交易博弈策略转向**运营能力和风险防控**」）；⭐⭐ **库内首次把「一次申报」与「绿证/绿电台账」挂上钩** —— 库内 11-19 已记 92 号文要求「物理可溯源」与库内 11-15 已记 1565 号文要求细化的规则清单（注册准入 / 申报交易 / 计量结算），**本篇首次出现「申报」这一动作本身的形态变化**；⚠️ **成交电量存在两源差异（61.7 亿 vs 62 亿千瓦时）**，须并列登记；⚠️ **库内无我方参与绿电交易的证据 → 不得下「我方受影响」结论**。

## 四、概要提取

- ⭐⭐⭐ **11-26 国家电网召开西北—华东绿电联合交易启动会，省间与省内两级绿电市场首次在同一套规则下实现「一次申报、联合交易」**，首单成交电量 **61.7 亿千瓦时**（其中西北跨区送华东 19.5 亿千瓦时，占 **31.6%**）。
- ⭐⭐⭐ **市场覆盖上海、江苏、浙江、安徽、福建、陕西、甘肃、青海、宁夏、新疆十省区市**；**1615 家经营主体**参与，其中 **427 家售电公司与电力用户**匹配到 **1188 家发电企业**的绿电资源（**427 + 1188 = 1615，与参与主体总数完全自洽**）→ **供给侧主体数是购电侧的 2.8 倍**。
- ⭐⭐⭐ **机制变化的准确表述**：过去省间、省内**分别申报、分别出清**；现在**一次提出量价需求（要多少、何时要、何价要），市场在全国范围分解匹配供需，同步生成省间与省内成交结果**；央视网给出实例 —— 江苏一家出口外向型制造业企业**一次申报即同时购得新疆等省区与江苏省内的绿电**。
- ⭐⭐⭐ **上位依据落地**：国办发〔2026〕4 号要求「跨省跨区和省内交易要由分别组织逐步转向联合交易」，**绿电率先落地**；联合市场将**转入常态化组织**，逐步扩大交易范围与交易周期。
- ⭐⭐ **官方对发电侧的判断值得单独记**：「项目收益逻辑**从交易博弈策略转向运营能力和风险防控**」—— **收益重心从价格博弈移到运营能力**，这是对我方聚合与运营能力方向上的利好表述。
- ⭐⭐ **跨省富余通道空间被同步激活**（北京电力交易中心新能源交易部主任刘硕），与库内 11-19 已记的 92 号文「跨省跨区外送不区分电源类型」方向一致。
- ⭐⭐ **⚠️ 成交电量两源不一致**：中国能源新闻网记 **61.7 亿千瓦时**，央视网记 **62 亿千瓦时** → 两者应理解为「精确值 vs 概数」，**但仍须并列登记**。
- ⭐⭐ **⚠️ 官方对用能企业成本的影响只有定性表述**（「可以降低用能企业成本」），**无任何数字** → 不得据此测算成本降幅。

## 五、主要观点

**原文主张**

- 中国能源新闻网：联合交易将两级市场融合为统一市场，用户侧只报「要多少、何时要、何价要」，发电侧的「项目收益逻辑从交易博弈策略转向**运营能力和风险防控**」；跨省跨区与省内首次在同一规则下运行，是「目前全球最大的绿电交易市场」；国办发〔2026〕4 号要求的联合交易「绿电率先落地」；市场将转入常态化组织。
- 央视网：本次联合交易打通了省间与省内两级绿电市场，**跨省跨区的富余通道空间得到进一步充分利用**；江苏一家面向海外市场的制造业企业一次申报即同时购得跨省与省内绿电。

**我方判断**

- ⭐⭐⭐ **这份情报对我方的价值不在「绿电市场变大了」，而在「申报动作的形态变了」—— 这是一个我方系统必须适配的具体变化。** 库内 11-19 已记 92 号文要求绿电台账建「证—电量—场站—时段」四层可对账关系，库内 11-15 已记 1565 号文要求细化「注册准入 / 申报交易 / 计量结算」，**但那两条讲的都是「要有哪些规则」，从没讲过「申报长什么样」**。**本篇第一次给出了申报侧的具体形态：一次申报 → 量 / 时 / 价三元 → 平台分解匹配 → 同步生成两级成交结果。** 对我方的直接含义是：**如果我方（无论作为聚合商侧工具、售电侧服务还是用能侧代理）参与绿电采购，我方系统的申报接口要支持「一次提交、省间省内同时匹配」的语义，而不是「分别向两个市场各申报一次」。** ⚠️ 库内无产品材料，**不得替我方产品下结论**，只能作为待决问题登记 —— 但**这个问题的答案不取决于情报，而取决于我方是否要接这块业务**，所以它值得被明确提出。
- ⭐⭐⭐ **「427 售电+用户 对 1188 发电企业」这个 2.8 倍的结构比 61.7 亿这个数字更有信息量。** 供给侧主体数是购电侧的近三倍，意味着**绿电侧极度分散、购电侧相对集中**。**这个结构与我方库内 11-19 记的虚拟电厂报告资源构成占比（可调节负荷 80.2% / 分布式电源 4.4% / 储能 3.6%）合起来读，指向同一个判断：我方所处的分布式资源侧在这个市场里是分散供给方，不是规则制定方，也不是价格制定方。** **我方的机会在「给大量中小主体提供合规的报价与结算工具」，而不是「在市场里定价」** —— **这与库内 11-19 已得出的「我方机会更可能来自给大量中小聚合商做工具与标准化服务」结论完全一致，且本期给了它一个新的量化支撑（供给侧 1188 : 购电侧 427 的主体结构）**。
- ⭐⭐⭐ **「一次申报」改变的其实是购电侧的决策模型，而且官方已经把新决策模型说出来了 —— 这是三条对未来的预判，值得逐条记住。** 官方说发电侧「不必再揣摩省间与省内价格孰高、通道与消纳空间几何」→ **通道可得性与消纳空间将不再由单个经营主体在申报时自行权衡，而由平台统一分解匹配**。这意味着**未来绿电交易中的差异化能力，将更多来自「报得好」而不是「算得准」**。对我方的含义：**如果我方业务里有任何「跨省跨区通道可得性测算」或「省间价差预判」类的功能，它们在联合交易形态下的价值会下降**；反过来，**「一次报价如何被拆分到省间与省内两笔成交」这件事本身，会变成一个新的、我方可能需要理解的对账问题** —— 因为同一笔成交对应两个物理来源、两条结算路径。**这与库内 11-19 记的 92 号文「不区分电源类型整体结算 → 我方按电源分别建模的口径会断裂」是同一类断裂风险的新形态：不是结算不区分电源，而是同一笔申报被拆成两笔不同来源的成交。** ⚠️ **原文未说明成交拆分后各侧的结算与绿证归属规则如何处理 → 必须开待决问题，不得替规则填空。**
- ⭐⭐⭐ **官方那句「收益逻辑从交易博弈策略转向运营能力和风险防控」，对整个光伏/绿电产业链是一句重话，我方应当记住并跟踪它的落地含义。** 如果发电侧的收益确定性来自「运营能力」而非「价格博弈」，那么**能证明自己运营能力（出力预测、可调可控、绿电溯源、绿证台账）的一方会比能预判价格的一方更有议价权**。**这恰好是我方业务条线所在的方向** —— 但**必须克制**：本期只给了一句定性，没有任何配套规则、没有任何考核口径、也没有任何一家发电企业被点名。**正确读法是「这是官方给出的方向信号，可作为长期跟踪项」，不是「政策红利已落地」。**
- ⭐⭐ **首单的性质要说准：这是一个「机制首秀」，不是「市场规模」**。61.7 亿千瓦时是一个交易日、十个省区市的成交电量；央视网称其「全球最大绿电交易市场」指的是**平台覆盖范围（十省区市、两级市场贯通）**，不是单日成交量。**库内 11-19 记虚拟电厂报告时反复警惕的「拿一个数字当规模」的同类错误，在这里必须避免** —— **不得写「绿电市场规模 61.7 亿千瓦时」**。同理**跨省占比 31.6% 说明当前联合交易仍以省内为主**，联合交易的「联合」价值尚未充分显现。
- ⭐⭐ **两条必须守住的口径纪律**：① **成交电量两源不一致（61.7 vs 62），并列登记** —— 这与库内 11-19 已记的「同一份硅业分会转载快照内出现两套并存价格」是同一类现象，处置方式相同：**不取其一、不取均值**；② **官方对成本的影响只有定性** —— 不得据此做任何成本测算或对客话术。
- ⭐ **一条容易被忽略但可能很重要的观察：央视网的实例是「一家面向海外市场的制造业企业」。** 库内 11-19 已记 124 号文与工信部 77 号文中「出口外向型工业企业」反复出现 —— **而本期联合交易的首个被点名的实例类型，正是出口外向型企业**。**这可能意味着「出口外向型用能企业的绿电采购」正是联合交易的主要目标客群**（逻辑上成立：这类企业同时面临绿电需求与出海合规/碳足迹要求）。⚠️ **单一实例，不足以证成客群判断，登记为观察项。**
- ⭐ **与我方的关系判定**：库内无任何我方参与绿电交易的证据，**不下「我方受影响」结论**。但**本篇给库内带来的最大价值是把三个已经悬着的问题串起来了**：① 库内 11-19 的「跨省跨区交易」方向 → ② 库内 11-19 的「国办发〔2026〕4 号」→ ③ 本篇的绿电落地形态。**三者是同一条线，而本篇是这条线上第一个有具体机制、有具体数字、有具体实例的节点。** 这条线此前在库内只是「政策方向」，本期开始有「可观测的市场事件」—— **对周报与月报而言，这条线的观察价值在上升。**

## 七、总结输出

**一句话结论**：11-26 国家电网西北—华东绿电联合交易启动会标志**库内首条「绿电交易机制并轨」** —— 省间与省内两级市场首次在同一规则下实现「**一次申报、联合交易**」，首单成交 **61.7 亿千瓦时**（西北跨区送华东 19.5 亿、占 31.6%，央视网另记概数 62 亿，两源并列），覆盖十省区市、**1615 家经营主体（427 售电与用户 : 1188 发电企业，供给侧为购电侧 2.8 倍，三数自洽）**，且央视网实例显示一家出口外向型制造业企业**一次申报即同时购得跨省与省内绿电**；这是**国办发〔2026〕4 号「跨省跨区和省内交易由分别组织逐步转向联合交易」在绿电品种上的首个落地**，官方并称发电侧「**项目收益逻辑从交易博弈策略转向运营能力和风险防控**」—— **对我方的真正含义有两条**：① **申报动作的形态变了**（一次提交量/时/价 → 平台分解匹配 → 同步生成两级成交），若我方接绿电采购或售电服务，**申报与对账模型需能表达「一笔申报拆成多笔不同物理来源的成交」**（与库内 11-19 已记 92 号文「不区分电源类型结算导致我方按电源建模断裂」是同一类断裂的新形态）；② **供给侧 1188 : 购电侧 427 的结构，再次印证库内 11-19 的判断 —— 我方在绿电市场里的位置是分散供给侧，机会在「给大量中小主体做报价与结算工具」而非定价**；⚠️ **官方对用能企业成本的影响仅有定性、无数字，我方无参与证据，不得下我方受影响结论**。
