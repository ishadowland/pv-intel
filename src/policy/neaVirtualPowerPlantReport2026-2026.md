| **⭐⭐⭐ 项目数量与调节能力（核心数字）** | 能源局官网转载新华社：《截至今年6月底全国已建成并投运592个虚拟电厂项目》：*"截至2026年6月底，全国已建成并投运的虚拟电厂项目数量为 **592 个，同比增长 78.9%**；最大调节能力达到 **2042.8 万千瓦，同比增长 62.7%**"*；光明日报（张翼）：同两个数字 + *"我国虚拟电厂规模快速增长"*；李建锋解读：*"截至2026年6月，全国已建成投运虚拟电厂 **592 个**、最大调节能力 **2042.8 万千瓦**"*；凡鹏飞解读：同 | **四源逐字比对**（官网新华社稿 + 光明日报 + 两篇官网署名解读） | ✅ **已核（四源一致）** | ⭐⭐⭐ **库内第一份虚拟电厂国家级量化基线**。⭐⭐ **注意两个增速的差异是有含义的**：**项目数 +78.9% 快于调节能力 +62.7%** → **平均单体规模在变小**（库内首次可推出此趋势，⚠️ 属**基于官方两个增速的推算**，非官方原文）→ **"虚拟电厂"正从少数大型基地型运营商走向大量中小型聚合商**。⚠️ **口径纪律**：**"项目数量"≠"运营主体数量"**，官方明确"592 个虚拟电厂**项目**"，而项目可由同一主体运营 → **不得写成"592 家运营商"** |
| **⭐⭐⭐ 资源构成四分类占比** | 光明日报：*"截至今年6月底，**可调节负荷、分布式电源、储能、电动汽车充换电设施各类型资源容量占比分别为 80.2%、4.4%、3.6%、11.8%**"*；李建锋解读同向：*"资源类型持续拓展，涵盖分布式电源、可调负荷、用户侧储能、电动汽车充换电设施等"* | 光明日报快照逐字 + 李建锋解读交叉 | ✅ **已核（光明日报直给 + 官网解读印证口径存在）** | ⭐⭐⭐ **库内首次出现虚拟电厂的资源构成占比**。⭐⭐⭐ **对我方最关键的一个数：储能仅占 3.6%，是四类中最低**；⭐⭐ **分布式电源 4.4%，同样很低**。⚠️ **口径纪律**：**这是"资源容量占比"，不是"项目数占比"，也不是"调节能力贡献占比"** —— 官方未给后者。⭐⭐ **推论边界**：**储能占比低不等于储能不重要**（储能通常单位容量调节能力更高），**官方未给单位调节能力数据 → 不得推算储能的实际调节贡献**。⭐⭐ **对我方的直接含义**：**我方最擅长的两类资源（分布式光伏、储能）在虚拟电厂的资源池里合计仅 8.0%** → **这是本条对我方最重要的战略信号**（详见第 5、6 段） |
| **⭐⭐ 分区域分布** | 光明日报：*"截至今年6月底，**华东、南方、华北地区虚拟电厂项目数量分别为 286、105、89 个，占比分别为 48.3%、17.7%、15%；虚拟电厂最大调节能力分别达 669 万千瓦、496.4 万千瓦、513.4 万千瓦，占比分别为 32.7%、24.3%、25.1%**"* | 光明日报快照逐字 + 李建锋解读交叉（*"华东、南方、华北等地区调节需求场景丰富、电力市场建设进度较快，虚拟电厂发展相对领先、规模较大"*） | ✅ **已核（两源一致）** | ⭐⭐ **库内首次出现分区域量化分布**。⭐⭐ **一个有意思的错位：华东占项目数 48.3% 但只占调节能力 32.7%（项目密度高、单体小）；华北只占项目数 15% 却占调节能力 25.1%（单体大）** → **"华东单体小、华北单体大"**，与"项目数增速快于调节能力增速"互相印证。⚠️ **口径纪律**：**这是"华东/南方/华北"三区的口径，不是省份口径**；**官方未给出其余地区的数字**（三区合计项目 480/592 = 81.1%、调节能力 1678.8/2042.8 = 82.2%，⚠️ **这是基于官方数字的计算，不是官方表述**） |
| **⭐⭐ 上半年增量与提前完成目标** | 李建锋/凡鹏飞解读同：*"**与2025年底相比，2026年上半年虚拟电厂项目数量增加122个，最大调节能力增长357.2万千瓦、增速21.2%**"*；新华网解读：*"**提前实现《关于加快推进虚拟电厂发展的指导意见》提出的2027年调节能力不低于2000万千瓦目标**"*；中国经济网：*"**提前完成2027年调节能力目标**"* | 三源逐字 + 与"592 个 / 2042.8 万千瓦"做算术自洽核对 | ✅ **已核（三源一致 + 算术自洽）** | ⭐⭐ **算术自洽核对通过**：592 − 122 = **470 个**（2025 年底）；2042.8 − 357.2 = **1685.6 万千瓦**（2025 年底）→ 1685.6 → 2042.8 = **+21.2%**，与官方"增速 21.2%"**完全吻合** → **内部一致性获验证**。⭐⭐ **关键结论：库内 11-15 已记的《"十五五"新型储能实施方案》把虚拟电厂列为"独立电站、储能聚合商、虚拟电厂"三形式之一，而本条给出其市场规模的第一个官方实数** → **2027 年 2000 万千瓦目标已提前一年半完成（数据截止 2026-06）**，官方随即把 2030 目标抬到 **5000 万千瓦**（见下条） |

## 四、概要提取

- **国家能源局 11-19 正式发布《中国虚拟电厂发展报告（2026）》（索引号 000019705/2026-000186）** —— 库内第一份虚拟电厂国家级发展报告，**虚拟电厂从"政策名词"变成"可算的产业"**。
- **规模基线四源互证**：截至 2026-06 底，**592 个已建成投运项目（+78.9%）、最大调节能力 2042.8 万千瓦（+62.7%）**、**提前完成** 2027 年 2000 万千瓦目标；**上半年增 122 个项目 / 357.2 万千瓦（+21.2%）**，算术自洽核对通过（470 → 592 个、1685.6 → 2042.8 万千瓦）。
- **⭐⭐⭐ 库内首次出现资源构成占比**：**可调节负荷 80.2% / 电动汽车充换电 11.8% / 分布式电源 4.4% / 储能 3.6%** —— **我方最擅长的两类资源合计仅 8.0%**；且**项目数增速（78.9%）快于调节能力增速（62.7%）→ 平均单体规模在变小**，虚拟电厂正从少数大型基地型走向大量中小型聚合商。
- **⭐⭐ 政策重心下沉的三项可对接口径**：省级配套文件已覆盖 **23 个省区市**，政策重心下沉至 **可调能力核验 / 接入调用管控 / 交易结算** —— 恰好对应我方的能力评估、接入调度、交易结算三个接口面；官方同时点名要细化 **注册准入 / 申报交易 / 计量结算** 三类规则 + 参与中长期/现货/辅助服务三类市场 + 跨省跨区交易。
- **2030 年目标 5000 万千瓦**（出自《新型电力系统建设"十五五"规划》，首次将虚拟电厂纳入国家规划），首批 **13 个**国家试点、**3 项国标已发布**（虚拟电厂管理规范 / 资源配置与评估技术规范 / 技术导则）+ 30 余项团标；官方自述短板为"**部分主体运营水平不高、资源精细化调控能力不足**"与"部分市场交易规则待健全"；可核实绩为 **上海 7-16 调用削峰 165 万千瓦 = 全市最大负荷 4%**。

## 五、主要观点

**原文主张**

- 国家能源局（报告编制方）：虚拟电厂是"聚合分布式电源、可调节负荷、储能等各类分散资源，作为**新型经营主体**协同参与电力系统优化和电力市场交易的电力运行组织模式"；"十五五"期间将持续扩张，但须"**强化政策引导供给、持续培育优质运营商主体**"，并"**不断强化聚合资源能力评估校验，提升实时协同、精准响应调控水平**"。
- 李建锋（电科院副总工）：规模"提前完成《指导意见》确立的 2027 年发展目标"；资源类型持续拓展；2030 年 5000 万千瓦目标"对资源聚合、市场运营和**安全保障能力**提出了更高要求"。
- 凡鹏飞（电规总院院长）：顶层设计三大亮点（首个国家专项政策、首次纳入国家电力发展规划、公布首批国家试点）；地方政策"**重心由总体方案谋划下沉至可调能力核验、接入调用管控、交易结算**"；短板是"部分主体运营水平不高、资源精细化调控能力不足"。
- 陈玮（南网能源院总经理）：**"从'聚起来'到'用得好'"** —— "未来既要重视'**聚得多**'，也要重视'**配得优**'，通过多类型资源互补提升调节的**可靠性和经济性**，避免将虚拟电厂简单等同于…"（**原文在此处截断**，见第 2 段边界）；并强调"负荷资源仍占主体，**分布式电源、储能等资源的聚合潜力尚未充分释放**"。
- 新华网解读：标准体系"覆盖资源接入、聚合调控、并网测试、运行管理、**安全防护**全业务环节"；5G 边缘终端与**国产化运营平台**加速落地；5G 支撑海量分散资源"**可观、可测、可控**"。

**我方判断**

- ⭐⭐⭐ **本条对我方最重要的一句话，不在规模数字里，而在"80.2% / 4.4% / 3.6% / 11.8%"里。** ⭐⭐ **我方的两类核心资产（分布式光伏 4.4%、储能 3.6%）在虚拟电厂的资源池中合计只有 8.0%，可调节负荷一家占 80.2%** —— 这意味着**"把分布式光伏和储能聚成虚拟电厂"这个叙事，在当前的市场结构里是边缘叙事，不是主流**。⭐⭐ **同时官方自己也在说同一件事**（陈玮："负荷资源仍占主体，分布式电源、储能等资源的聚合潜力**尚未充分释放**"）→ **这不是官方在否定这个方向，而是在说"这个方向的空间还没打开"**。⭐⭐ **对我方的正确结论不是"退出虚拟电厂"，而是"这 8.0% 是当前唯一未被充分开发的部分，机会在于'未充分释放'而不是'已经很大'"** —— 但要清醒：**它小**。
- ⭐⭐⭐ **对我方最可执行的一条，是官方两次点名的规则清单：省级文件"下沉至可调能力核验、接入调用管控、交易结算" + 国家层面要细化"注册准入、申报交易、计量结算"、参与"中长期/现货/辅助服务"三类市场**。⭐⭐ **这三组词几乎逐字对应我方产品的三个接口面** → **我方不需要新造能力，只需要确认现有模块能否以"聚合商主体"的身份承载这三类规则**。⭐⭐ 而且**这条确定性很高**：**库内 11-15 已记《"十五五"新型储能实施方案》（1565 号文）要求细化的正是"注册准入、申报交易、计量结算"** → **两条独立国家级文件在同一年给出同一套清单，说明这是官方反复强调的方向，不是一次性表态** → **我方的交易/结算数据结构应优先按这套清单做一次自检**（⚠️ 库内 11-15 已记我方 `requirement-tradeContractSchema` 产物含 `marketScope`（跨省跨区）、`contractTermType`（多年期）、品种明细子表、`participantType`、`aggregationMode` —— **其中 `participantType`（参与主体类型）与 `aggregationMode`（聚合模式）两个字段正是本条所指规则的落点，应对照本条做一次定向复核**）。
- ⭐⭐ **第二个可执行判断：虚拟电厂被官方定义为"新型经营主体"，这对我方的身份定位是硬约束。** ⭐⭐ **"592 个项目"不是"592 家运营商"** → **官方同时自述"部分主体运营水平不高"** → 这意味着**在这个市场里，"主体身份"本身是有门槛的**（资格、信用、履约记录）。⭐⭐ **对我方的启示**：我方更现实的定位是**给聚合商与运营商提供技术底座（可调能力核验、接入调用管控、交易结算）**，而不是自己去抢"新型经营主体"这个身份 —— 除非我方已具备市场主体的资格与信用资质，**这一点库内无材料可查 → 属"待核实"，不得假设我方具备或不具备**。
- ⭐⭐ **第三个判断：标准体系里"安全防护"是一个正式环节，这是本条对我方安全方向的唯一入口，但入口很窄。** ⭐⭐ 官方把虚拟电厂标准覆盖面明确列为"资源接入、聚合调控、并网测试、运行管理、**安全防护**"五环节 → **我方的接入认证、调用管控、边界防护能力在虚拟电厂场景会成为运营商的合规配套需求**。⚠️ **但标准正文未取得、官方解读未给任何安全条款 → 本条不足以支撑任何我方安全动作** → **正确处理是列为"跟踪项 + 开 issue 等标准正文"**，**不是**转评审。⚠️ **尤其不得**因为"安全防护"四个字就把它塞进网络安全方向的评审（那会犯库内 11-15 已记录的"凭一个词推产品结论"的错）。
- ⭐⭐ **第四个判断：增长结构比总量更重要。** 项目数 +78.9% 快于调节能力 +62.7%，且华东项目数占 48.3% 但调节能力只占 32.7%（华北反向：15% vs 25.1%）→ **市场在快速碎片化，单体规模在下降**。⭐⭐ **对我方的含义**：**虚拟电厂不是一个"少数玩家做大平台"的市场，而是一个"大量中小聚合商"的市場** → **我方的商业机会更可能来自"给大量中小聚合商做工具/标准化服务"，而不是"自建一个平台吃下 5000 万千瓦"**。⭐⭐ **这与库内 11-19 已记的 92 号文"鼓励主体优化整合、聚合/打捆成为政策准入前置条件"方向一致** —— 但**政策在推整合，市场在碎片化**，这个张力值得持续盯。
- ⭐⭐ **第五个判断：上海 7-16 的"165 万千瓦 / 4%"这个数，价值在于它确认了"需求侧调用已成为保供手段"这个事实，不在于它能被用来算钱。** ⚠️ **样本只有 1 次、未给持续时长、未给价格、未给调用的是哪些资源** → **不得进收益模型**。⭐⭐ **它的正确用法是：当客户问"光伏+储能能不能参与需求响应"时，可以给出"在一个真实的最大负荷日，上海用虚拟电厂削掉了全市 4% 的峰值"这个量级参照**。
- ⚠️ **最后一条纪律**：**本条是产业与政策域，不属五方向，任何"我方要上虚拟电厂平台"的产品决策都不能从这条直接推出** —— 它提供的是**规模基线、规则方向与接口面清单**，产品决策要等**规则正文（注册准入/申报交易/计量结算）与标准正文**到位后再做。

## 七、总结输出

**一句话结论**：**国家能源局 11-19 正式发布《中国虚拟电厂发展报告（2026）》（索引号 000019705/2026-000186、制发日期 2026-11-19），这是库内第一份虚拟电厂的国家级发展报告，把虚拟电厂从"政策名词"变成了"可算的产业"—— 截至 2026-06 底全国已建成投运 592 个项目（同比 +78.9%）、最大调节能力 2042.8 万千瓦（同比 +62.7%）、提前完成 2027 年 2000 万千瓦目标（上半年增 122 个 / 357.2 万千瓦，+21.2%，算术自洽核对通过），并给出 2030 年超 5000 万千瓦的国家目标（出自《新型电力系统建设"十五五"规划》，该规划首次将虚拟电厂纳入、首批 13 个国家试点、3 项国标已发布 + 30 余项团标、23 个省区市已出配套文件）；⭐⭐⭐ **但本条对我方最重要的一组数不是规模，而是库内首次出现的资源构成占比：可调节负荷 80.2% / 电动汽车充换电 11.8% / 分布式电源 4.4% / 储能 3.6% —— 我方最擅长的两类资源合计仅 8.0%，官方自己也承认"负荷资源仍占主体，分布式电源、储能等资源的聚合潜力尚未充分释放"**，因此对我方的正确读法是"机会在未被充分开发的部分，但它小"，而非"这是一个大市场"；⭐⭐ **另有一个结构性判断**：**项目数增速（78.9%）快于调节能力增速（62.7%），且华东项目数占 48.3% 但调节能力只占 32.7%（华北反向 15% vs 25.1%）→ 市场在快速碎片化、单体规模在下降 → 我方的机会更可能来自"给大量中小聚合商做工具与标准化服务"，而非自建平台吃下 5000 万千瓦**；⭐⭐⭐ **最可执行的一条是官方两次点名的规则清单**（省级文件"政策重心下沉至可调能力核验、接入调用管控、交易结算" + 国家层面"细化注册准入、申报交易、计量结算，参与中长期/现货/辅助服务市场，探索跨省跨区交易"）—— **它与库内 11-15 已记《"十五五"新型储能实施方案》（1565 号文）要求细化的规则完全同款，两条独立国家级文件同年给出同一套清单 → 确定性很高，且恰好逐字对应我方的能力评估、接入调度、交易结算三个接口面与既有产物 `requirement-tradeContractSchema` 的 `participantType` / `aggregationMode` 两个字段**；⭐ **官方把虚拟电厂定性为"新型经营主体"且同时自述"部分主体运营水平不高" → 我方更现实的定位是能力与工具供给方（是否具备市场主体资格库内无材料，归待核实）**；⭐ **可核实绩仅一条**（上海 7-16 调用虚拟电厂削峰 165 万千瓦 = 全市最大负荷 4%）—— 可作"调用能力量级"参照，**但样本 1 次、无价格无时长，不得进收益模型**；⚠️ **必须写明的六条边界**：**报告 PDF 全文未取得（条款级内容全部依赖官方署名解读与官方转载媒体稿，但可信度结构好 —— 三篇解读分别署名电科院副总工李建锋 / 电规总院院长凡鹏飞 / 南网能源院总经理陈玮，三源独立互不重复，核心数字另有新华社与光明日报复核）；"592 个"是项目数不是运营主体数；80.2/4.4/3.6/11.8 是资源容量占比、官方未给调节能力贡献占比；165 万千瓦是一次调用的结果不是可调用能力；5000 万千瓦出自"十五五"规划不是本报告新设；"国产化运营平台"是政策倾向不构成厂商推荐**；⚠️ **另有一条必须克制的地方**：官方解读把"安全防护"列为标准覆盖环节，但**标准正文未取得、三篇解读零安全条款 → 本条不足以支撑任何我方安全动作，只登记为跟踪项，绝不凭"安全防护"一词转评审**。

**落地去向**

- [ ] **产品特性** —— ❌ **不勾**（本阶段口径：转评审只到方向级，不落产品功能改造）；⭐ **可记入方向级观察项**：虚拟电厂"可调能力核验 / 接入调用管控 / 交易结算"三件套服务、聚合商主体的结算关系表达
- [ ] **需求变更** —— 🟡 **待复核**：① **对既有 `requirement-tradeContractSchema` 产物做一次定向复核** —— 官方两次点名的"注册准入 / 申报交易 / 计量结算 + 中长期/现货/辅助服务三类市场"必须能由 `participantType`（聚合商作为新型经营主体）、`aggregationMode`、品种明细子表完整承载；② **能力评估模型与接入调度接口输出"可调能力核验"标准形态**（可观/可测/可调/可控四性，官方标准已沿用与 7 号文同款措辞）；③ **收益模型登记三项参数缺口**：虚拟电厂结算价、单位调节能力、调用持续时长 —— **官方本期未给，严禁以辅助服务价或需求响应价替代**
- [ ] **专项整改** —— ❌ **不勾**（第 1 关不过：属产业/经营参数域，不属五方向；且无我方侧一手证据）
- [ ] **跟踪项** —— ⭐⭐ **建议开 issue（待决 · 新开）**：**"虚拟电厂主体身份与规则就绪度自检"** —— 背景为本报告 + 1565 号文同款规则清单 + 库内无我方主体资格与聚合商对接材料；**选项至少两个**（A. 只做"可调能力核验 / 接入调用管控 / 交易结算"工具与标准化服务供给，不自建运营主体；B. 以聚合商主体身份直接参与中长期/现货/辅助服务市场），**倾向 A**（官方已定性"新型经营主体"且自述"部分主体运营水平不高"，我方主体资格与信用资质库内无材料可查，贸然自建主体风险不可评估）；**影响面**为交易与结算数据结构、能力评估模型、接入调度接口、业务组合策略；**关联文档**本篇 + [storagePlan15thFiveth-2026](../policy/storagePlan15thFiveth-2026.md) + [requirement-tradeContractSchema](../deliverables/requirement-tradeContractSchema-20261112.md)
- [ ] **跟踪项** —— ① **《中国虚拟电厂发展报告（2026）》PDF 原文补齐**（官网仅给下载链接，本期条款级全部依赖二手）；② **虚拟电厂三项国标正文**（管理规范 / 资源配置与评估技术规范 / 技术导则）—— **特别是"安全防护"环节的安全条款，这是本条在网络安全方向的唯一入口**；③ **虚拟电厂结算价与单位调节能力**（收益模型硬缺口）；④ **23 个省区市的地方文件与 13 个国家试点名单**（官方只给总数）；⑤ **"分布式电源 + 储能合计 8.0%"这一占比的官方定义口径**（容量占比 vs 调节能力贡献，官方未给后者）
