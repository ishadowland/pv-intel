## 四、概要提取

- ⭐⭐⭐ **库内首次出现「四可」改造的双档硬截止日**：工商业及非自然人户用存量项目 **≥400 kW 须于 2026-12-15 前**完成（**距今 20 天**）、**<400 kW 须于 2027-12-15 前**完成；自然人户用"按需"无期限 → **≥400 kW 档恰好覆盖我方主战场（工商业分布式）的绝大部分体量**。
- ⭐⭐⭐ **库内首次写清「四可」改造设备清单与投资界面**：产权分界点内「可调、可控」设备由**项目投资主体**投资建设，清单含 **光伏断路器 / 协议转换单元 / 分支装置 / 并网点开关 / 边缘网关 / 配网安全防护终端** 六类 → **其中协议转换单元、分支装置、边缘网关、配网安全防护终端四项即我方能力所在区间**（库内无产品材料，不得声称对应）。
- ⭐⭐⭐ **库内首条「改造费用归属」的硬日期分界**：**2026-07-20 之前报装的存量公变低压项目，「四可」设备由电网企业投资建设；之后由用户自行投资** → **决定改造报价的归属方是电网侧采购还是用户侧采购**；⚠️ 适用范围极窄（"存量公变低压"），范围外工商业项目一律用户自投。
- ⭐⭐⭐ **「达不到标准的项目，电网企业不予并网接入」= 库内首次出现「四可」作为并网准入条件的地方级执行口径** → **此前库内只记"要求四可"，没有"不满足即拒绝并网"这一后果**；**这把四可从合规要求变成了交易条件**。
- ⭐⭐⭐ **电网侧三项常态化义务**：摸排存量项目台账、建立「四可」改造项目清单与实施计划、**常态化开展「四可」能力巡检并定期组织全流程调控测试**、排查"电网侧、用户侧系统、硬件及通信通道隐患"、**"保障光伏调控能力持续在线可用"** → **库内第一次出现由电网侧组织的全流程调控能力测试义务**。
- ⭐⭐ **责任分配成对**：电网负责测试与巡检，**投资主体负责自有范围内设备日常运维并"保障通信通道稳定畅通"** → **通信通道可用性是我方托管服务合同里必须写明的指标**。
- ⭐⭐ **库内地方落地形态的第 4 种**（此前 3 种：容量公示 / 备案服务指南 / 项目建设管理通知），且**是首个带截止日与投资界面划分的形态** → **地方政策环境正在从"程序性"转入"强制性"**。
- ⚠️ **四条边界**：**地市级文件，不可当全国口径**；**"四可"的具体技术指标不在本文件内**；**属补漏入库（成文 2026-09-30、发布 2026-10-12）**；**库内无我方在韶关的项目台账 → 不得下"我方需立即改造"结论**。

## 五、主要观点

**原文主张**

- **韶关市发展和改革局**：根据 7 号文要求，新建分布式光伏发电项目需实现"可观、可测、可调、可控"；为提升韶关市并网调控水平、规范存量项目改造实施，制定本通知。**总体要求**：新建项目须满足"四可"技术要求，**达不到标准的项目，电网企业不予并网接入**；存量项目按分类施策、分批推进原则有序实施改造。工作安排：① **新建项目自本文件印发之日起**须选用满足"四可"技术规范的设备，提交并网接入申请时需满足"四可"条件，**否则不予并网**；② **装机 ≥400 kW 的工商业、非自然人户用存量项目原则上 2026-12-15 前**完成改造；③ **<400 kW 原则上 2027-12-15 前**完成；④ **自然人户用存量项目结合电网运行实际按需实施**；⑤ **投资界面**：依 7 号文第二十九条、第三十三条，用户侧配套工程由项目投资主体投资建设、公共电网改造部分由电网企业投资建设、各方按产权分界点承担智能化改造及运维责任；**新建及存量项目原则上由项目投资主体在产权分界点内投资建设"可调、可控"相关设备（光伏断路器、协议转换单元、分支装置、并网点开关、边缘网关、配网安全防护终端等）**；**设置过渡期政策：2026-07-20 之前提交报装申请的存量公变低压分布式光伏项目（含非自然人户用、一般工商业），其产权分界点内"可调、可控"设备由电网企业负责投资建设；2026-07-20 之后提交报装申请的项目，相关设备由用户自行投资建设**。工作要求：市发改局统筹并督导；县区发改局宣传解读与协调；**电网企业全面摸排梳理全市存量分布式光伏项目台账、建立"四可"改造项目清单、编制改造实施计划、明确改造时序与区域范围、定期报送进展、常态化开展"四可"能力巡检、定期组织全流程调控测试、及时排查电网侧与用户侧系统及硬件与通信通道隐患、保障光伏调控能力持续在线可用**；**项目投资主体负责自有产权范围内"四可"设备日常运维、保障通信通道稳定畅通、配合电网企业开展调控测试**。
- **第三方转载（盖锡新能源 / 国际新能源网 / 北极星等）**：与官方原文逐字一致，无补充事实。

**我方判断**

- ⭐⭐⭐ **这份文件对我方最直接的意义是：它把「四可」从一条合规要求变成了三件带日期、带金额、带后果的商业事实 —— 而库内此前对 7 号文的全部记录都停留在"要求"层面。** ⭐⭐⭐ **第一，它有了后果**：*"达不到标准的项目，电网企业不予并网接入"* → **对新建项目，我方方案里的设备选型若不含四可要素，方案不可交付** → **这是一条直接影响方案可交付性的准入条件，不是软性倡议**。⭐⭐⭐ **第二，它有了钱和归属**：产权分界点内的"可调、可控"设备由投资主体出资，清单六项中四项落在软件/通信/安全区间 → **这划出了我方商业机会的边界，同时也划出了责任边界**。⭐⭐⭐ **第三，它有了时间**：≥400 kW 存量 2026-12-15（**20 天**）、<400 kW 2027-12-15 → **改造窗口是分档的，不是整体的** → **对我方存量服务业务而言，这是一个有时限的、可以按容量档排期的服务需求**。⭐⭐⭐ **值得单独强调的是"配网安全防护终端"这一项**：**库内至今所有安全情报的暴露面都是"公网站点 / OT 设备 / 云平台 / 制冷控制器"，而"配网安全防护终端"是第一条被地方政策明确写进投资清单的安全设备** → **我方安全能力第一次在一个地方级分布式改造文件里被点名到一个具体设备名**（⚠️ **但库内无我方产品材料 → 不得声称我方产品即该终端，只能说"这是第一条把安全终端写进改造投资清单的地方记录"**）。
- ⭐⭐⭐ **「2026-07-20 投资界面过渡期」这一条，是全篇最容易被漏掉、但对我方商务口径最硬的一条。** ⭐⭐⭐ **同一条规则在 7 月 20 日前后，设备钱的归属方从电网企业变成用户** → **对我方报价单而言，这是一个必须分列的字段：改造方案是报给电网侧采购，还是报给用户侧采购**。⭐⭐ **如果我方不区分这条边界，同一套设备在不同项目上的报价归属与毛利结构会完全不同** → **可执行动作：项目台账新增「报装申请日期」字段，并据此自动判定改造费用归属方**。⭐⭐ **注意范围**：该过渡期只覆盖**"存量公变低压"**（含非自然人户用、一般工商业），**范围之外的工商业项目（多为专线、高压）一律用户自行投资** → **而工商业分布式的典型形态恰恰大量是专线接入** → **也就是说：这条对多数工商业存量项目并不适用，只有低压公变项目能吃到"电网企业出钱"**。⭐⭐ **这条判断必须写清，否则容易产生"改造是电网企业出钱的"错误普遍化预期。**
- ⭐⭐⭐ **「全流程调控测试」是我方能力第一次出现在地方级硬性测试义务里 —— 这件事的分量不在"多了一个测试"，而在于"谁来做验证"变了。** ⭐⭐⭐ **此前我方对自己"可调可控"能力的证明方式是自证（方案、参数、演示）；这份文件要求的是**电网侧组织的全流程调控测试 + 常态化能力巡检**，并且明确把排查对象扩展到**"电网侧、用户侧系统、硬件及通信通道"**，最终指标是**"保障光伏调控能力持续在线可用"**。⭐⭐ **这是一个方向级、可验收、且有考核性质的外部验证机制** → **对我方的直接影响有两条**：① **我方的接入系统与通信链路可用性会被电网侧直接检验，不再只由客户验收** → 我方方案里的"通信通道稳定畅通"必须能被第三方持续检验；② **这天然对应一个可承接的服务形态：配合电网侧的巡检与测试的第三方运维/测试服务**，且**有明确政策依据可写进商务材料**（与库内 11-24 已记 45 号文"支持建设数字化能碳管理平台"属同一类"国家在推的能力"）。⭐⭐ **但必须同时写清边界：库内无我方产品能力材料、也无我方在韶关的项目台账 → 不得下"我方产品已满足全流程调控测试"或"我方需立即改造"之类结论**；正确做法是把它登记为一个**对我方能力有明确验收要求的外部机制**，并列出待核实项。
- ⭐⭐⭐ **责任分配这一对（电网测试 + 投资主体运维 + 通信通道责任）把我方托管服务里最容易被含糊掉的一条钉死了：通信通道的可用性是投资主体的责任，因此在我方承接托管的合同里，它必须是可量化的服务指标。** ⭐⭐ **原文把"保障通信通道稳定畅通"单列为运维管理要求 —— 这一条在库内其它政策文档里从未出现过**。⭐⭐⭐ **它的可执行含义**：我方托管服务合同中应明确**通信通道可用率、故障响应时限、以及我方与电网侧测试的配合义务**；否则"通道不通导致调控测试不过"这类责任争议会在交付期爆发。⭐⭐ **同时它和库内 11-24 已记的「第三方参与远程运维」议题、11-25 已记的「供应商代运维实例是影子密钥存活地」形成一条完整链**：**运维责任在投资主体 → 投资主体把运维外包 → 通道与账号的可见性风险落到平台方** → **这与我方"平台方是否应当成为发现方"的角色问题（见库内 11-25 Azure APIM 条目）完全同向**。
- ⭐⭐⭐ **"7 号文地方落地形态"这条线，本篇把它从 3 种推进到 4 种，而且这第 4 种是第一个带强制后果的 —— 这比任何单条政策都更值得记录，因为它说明的是趋势。** ⭐⭐⭐ **库内已记形态：① 容量公示（阿坝州、环县）② 备案服务指南（漳平、连城）③ 项目建设管理通知（宣城）** —— **这三类都是"程序性"的：告诉你容量在哪、怎么备案、怎么征求意见**。⭐⭐⭐ **本篇是"强制性"的：不改不给并网、谁出钱、什么时候改完、谁来测** → **这意味着 7 号文正在从"被地方当作接网与项目管理依据"进一步变成"被地方当作可考核的并网准入条件"**。⭐⭐ **对我方的判断意义**：**地方交付环境正在变硬而非变软** —— 我方在地方拓展分布式业务时，遇到的将不是"要不要做四可"这种软问题，而是"四可设备清单是否齐、改造是否在截止日前完成、能否通过电网侧全流程调控测试"这种硬交付问题。⭐⭐ **因此对我方的直接要求是：四可合规能力必须在方案阶段就作为默认项，而不是作为可选项或增值包** —— 但这属于产品侧判断，**库内无我方产品材料，本篇只登记为方向级约束，不替我方产品下结论**。
- ⭐⭐ **本篇对库内 7 号文文档的增量是"延伸落地"而非"新事件"** → **按去重纪律，本篇宜作为 7 号文文档「地方落地」节的补充（该节已记四例），而非重开一条国家政策线**；⭐⭐ **但它的可算量（两档截止日、2026-07-20 分界日、六类设备清单、三项电网侧义务）必须独立成篇**，因为这些数字在库内此前无任何出处。
- ⚠️ **必须保持的边界**：① **不得把地市级文件当全国口径**；② **不得把"四可"的技术指标自行代填**（本文件只要求"满足四可技术规范的设备"，指标真源在 7 号文与相关技术规范）；③ **不得把"原则上"写成"必须"**（两档期限原文均为"原则上"）；④ **不得把 2026-07-20 的过渡期政策普适化**（只覆盖存量公变低压）；⑤ **不得把"配网安全防护终端"写成我方产品**（库内无我方产品材料）；⑥ **不得下"我方需立即改造"结论**（库内无我方韶关项目台账）；⑦ **不得把 400 kW 线写成"大项目才要改、小项目不用管"**（<400 kW 档同样有 2027-12-15 的期限，只是更宽裕）。
- ⭐ **优先级判断**：**属市场/商务规则域 + 技术合规域，按本阶段五方向口径第 3′ 关不过 → 退回简报跟踪**；但其中**「配网安全防护终端」这一条与「全流程调控测试 + 持续在线可用」这一条具有方向级意义**，可转入网络安全方向的观察项（**不转评审，因缺我方侧一手证据**）。

## 七、总结输出

**一句话结论**：**韶关市发改局《加快推进全市分布式光伏发电项目「四可」接入改造工作的通知》（韶发改函〔2026〕123号，成文 2026-09-30、发布 2026-10-12，属补漏入库）把库内对 7 号文「四可」的全部停留在"要求"层面的记录，一次性推进成了三件带日期、带金额、带后果的商业事实 —— 因为库内此前只记了"新建项目须满足四可"，从未记录过"不满足就不给并网、谁出钱、什么时候改完、谁来测"；⭐⭐⭐ 具体是：① **「达不到标准的项目，电网企业不予并网接入」= 库内首次出现四可作为并网准入条件的地方级执行口径** → 四可从合规要求变成交易条件，我方方案里设备选型若不含四可要素即不可交付；② **双档硬截止日**：工商业及非自然人户用存量项目 **≥400 kW 须于 2026-12-15 前**完成改造（**距今仅 20 天**，而该档恰好覆盖我方主战场工商业分布式的绝大部分体量）、**<400 kW 须于 2027-12-15 前**、自然人户用"按需"无期限 → 改造需求是分档的、可按容量档排期的有时限服务需求；③ **投资界面首次写清**：产权分界点内「可调、可控」设备由投资主体出资，清单六类（**光伏断路器 / 协议转换单元 / 分支装置 / 并网点开关 / 边缘网关 / 配网安全防护终端**），其中后四项正落在软件通信安全区间，**而「配网安全防护终端」是库内首条被地方政策明确写进投资清单的安全设备**（⚠️ 库内无我方产品材料，不得声称我方产品即该终端）；④ **库内首条「改造费用归属」硬日期分界：2026-07-20 之前报装的存量公变低压项目，「四可」设备由电网企业投资建设，之后由用户自行投资** → 这决定改造报价归属方是电网侧采购还是用户侧采购，**但必须同时写清该过渡期只覆盖"存量公变低压"，而工商业分布式的典型形态大量是专线接入、并不适用这条普适化预期**；⑤ **⭐⭐⭐ 最有分量的一条是我方能力第一次进入地方级硬性测试义务 —— 电网企业须"全面摸排梳理全市存量项目台账、建立『四可』改造项目清单、常态化开展『四可』能力巡检、定期组织全流程调控测试"，并把排查对象扩展到"电网侧、用户侧系统、硬件及通信通道"，最终指标是"保障光伏调控能力持续在线可用"** → 此前我方对自己可调可控能力的证明方式是自证，这份文件要求的是**电网侧组织的持续外部验证**，直接意味着我方接入系统与通信链路的可用性会被第三方持续检验，**并天然对应一个"配合电网侧巡检与测试"的第三方服务形态（有明确政策依据可写进商务材料）**；⑥ **责任成对**：电网负责测试与巡检、**投资主体负责自有范围内设备日常运维并"保障通信通道稳定畅通"** → 通信通道可用性必须在我方托管合同里成为可量化指标与明确配合义务，否则交付期必然爆发责任争议；⑦ **从趋势看，这比单条政策更值得记录：库内已记 7 号文地方落地形态三种（容量公示 / 备案服务指南 / 项目建设管理通知）全是程序性的，本篇是第 4 种且是首个带强制后果的形态 → 地方政策环境正在从"程序性"转入"强制性"，我方面对的将不再是"要不要做四可"的软问题，而是"设备清单是否齐、改造是否在截止日前完成、能否通过电网侧全流程调控测试"的硬交付问题**。⚠️ 五条边界必须钉死：**地市级文件、约束范围仅韶关市，不可当全国口径**；**"四可"的具体技术指标不在本文件内、不得由本条代填**；**两档期限原文均为"原则上"，属软约束但有巡检与测试机制配合**；**不得把 2026-07-20 过渡期政策普适化**（仅存量公变低压）；**库内无我方在韶关的项目台账与产品材料 → 不得下"我方需立即改造"或"我方产品即配网安全防护终端"的结论**；**第 3′ 关（属市场/商务与技术合规规则域）不过 → 退回简报跟踪**，仅"配网侧设备与通信通道的持续可用性考核"作为方向级观察项登记（无我方侧一手证据、不转评审）。**
