## 三种简报的分工

| 周期 | 何时出 | 内容 | 读者动作 |
|---|---|---|---|
| **日报** | 每天 08:00 | 昨日新增情报（三大域）+ 变化摘要 | 扫一眼，标记感兴趣的 |
| **周报** | 每周一 09:00 | 上周情报归纳 + 趋势 + **评审预筛结果** | 判断哪些要进本月评审 |
| **月报** | 每月 1 日 09:00 | 上月总结 + 情报沉淀统计 + **产出域盘点** | 看产出节奏，评评审质量 |

## 与七段式的关系

**简报本身不是"文章"** —— 它是索引与归纳层，不重复做信源核实/事实核查/原文归档。

但简报里的**每一条情报条目都必须链到一篇七段式域文档**，那篇文档才承载：

| 段 | 承载位置 |
|---|---|
| 信源核实 / 事实核查 / 原文归档 / 概要提取 / 主要观点 | 域文档（`solar-industry/` `policy/` `security-intel/`） |
| 参考意义 | 域文档第 6 段 + 简报的传导说明 |
| 总结输出 | 域文档第 7 段 → 简报的评审预筛 |

> 换句话说：**简报里出现的情报，如果链不到一篇七段式文档，就说明采集没做扎实，该条应退回而不是照抄。**

## 硬约束

1. **简报不新增事实** —— 只做归纳与索引，所有细节链到采集域原文
2. **每条必须带链接** —— 指向 `src/` 下的原文，没有原文的不进简报
3. **日报 ≤ 1 屏** —— 详细分析放采集域，简报只给结论和钩子
4. **🔴 需立即关注** 段为空时也要保留该段并写"无"
