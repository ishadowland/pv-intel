## 1. 背景与证据

**本阶段口径（2026-11-12 用户明确）**：转评审只走 **网络安全 / 信创 / 等保 / 隐私保护 / 护网** 五个方向，**暂不要求精到具体产品** —— 库内尚无各产品线"特性 / 功能 / 应用场景"的结构化材料，凭情报做产品对应会失真。

本产物是**方向级**产物：把"电力行业真实存在的攻击手法"逐条对到我方**已有的**防线，输出覆盖度与缺口。**不新增产品功能，不依赖产品特性材料。**

### 证据 A —— 攻击手法侧（外部一手，已核）

来源：[院刊综述](../solar-industry/newTypePowerSystemSecurity-2026.md) §二、§五（DOI 10.15302/J-SSCAE-2025.12.002）

| 手法 | 论文原始表述要点 | 我方核查状态 |
|---|---|---|
| **FDI 虚假数据注入** | 利用状态估计器脆弱性**伪造测量数据**，欺骗控制中心、引发错误调度决策甚至电网故障 | ✅ 已核（原文 §二 事实核查） |
| **APT 长期潜伏** | 2024 年全球电力行业 **127 起**（同比 **+24%**），**41% 渗透至电力企业核心网络**，单次直接损失均值 **2200 万美元** | ✅ 已核（中国能源报同口径） |
| **强电磁脉冲 / 高频微波** | EMP 攻击覆盖范围广、频谱宽，可大量破坏电力电子设备，**导致极大范围内电力供应中断且难以恢复** | ✅ 已核（论文原文） |
| **分布式侧攻击面扩大** | 海量分布式用户接入使**电力系统网络攻击面急剧扩大**，安全风险更易穿透至系统核心 | ✅ 已核（论文原文） |
| **"信息–物理–社会"跨系统连锁** | 基础设施与**数据安全**易受跨系统连锁风险影响；能源管理系统软硬件漏洞持续暴露 | ✅ 已核（论文原文） |
| **防御侧框架** | 动态防御 · 工控协议防护 · 隐私计算 · 可信计算 · 云边端联动 · AI+因果推理 | ✅ 已核（论文原文） |

## 2. 影响面

| 方向 | 涉及面（既有资产，非产品特性） | 当前覆盖情况 |
|---|---|---|
| **网络安全** | 对外站点暴露面（`182.140.209.35:18443`、`idmo.pinnenger.com:11443`、`ptm.pinnenger.com:1443` 等）、发布流程、监控平台 API 鉴权 | 🟡 部分 —— 已有 P0 专项整改在跑（`.svn`/备份文件自查），但**手法维度的覆盖度从未系统盘过** |
| **护网** | 攻击手法分类与传导路径 | 🔴 无对照表 —— 手法分类散落在各篇情报里，**没有统一映射到防线** |
| **等保 / 关基** | 电力行业作为关键信息基础设施的防护基线 | 🔴 本库只有"合规基线"采集线（等保 2.0 / 关基保护 / 数据安全法），**尚无基线差距清单** |
| **信创 / 自主可控** | 柔直换流阀均压电阻长期依赖进口（单价约 1000 元、交付周期约 6 个月）；关键矿产对外依存；发达国家能源供应链转向本土及同盟 | 🟡 观察项 —— ⚠️ 论文该条与产业现状有张力（换流阀本体国产化已多轮鉴定），**不作"卡脖子"结论**；我方是否涉该类进口件，**库内无 BOM / 供应商资料** |
| **隐私保护** | 分布式侧海量"产消者"的用电与产消数据成为可操作对象；论文点名隐私计算 / 可信计算 | 🟡 方向级 —— 与 DER 暴露面研究指向同一面；具体隐私合规评估需我方数据清单，**库内不可查 → 待核实** |

## 3. 动作

### 做什么

- [ ] **建"攻击手法 → 我方防线"对照表**（本产物核心交付物）：以 §1 证据 A 的手法清单为行，逐条标注 **已覆盖 / 部分覆盖 / 未覆盖 / 不适用**，并**每行挂一条证据链接**（WAF 规则 / 报告事件 ID / 现有产物条目 / 采集源 URL）
- [ ] **行至少覆盖 6 类手法**：FDI 虚假数据注入 · APT 长期潜伏 · 认证绕过与越权读 · 运维通道窃取（`.svn` / 备份文件 / 数据库转储）· 错误信息与堆栈外泄 · 物理层攻击（EMP / 高频微波）
- [ ] **每行补一列"补强手段"**：对"部分覆盖 / 未覆盖"的行，写明**最小动作**（不是"加强防护"这种不可验收的写法）—— 例如"PTM 异常返回统一错误码，回归验证响应体不含 SQL/堆栈/内部路径"
- [ ] **补强动作与既有 P0 整改对齐**：手法表中的"运维通道窃取 / 错误信息外泄"两行直接引用 [对外站点暴露面专项自查](remediation-exposureHygiene-20261112.md)，**不另起炉灶**
- [ ] **"物理层攻击（EMP）"行按"不适用"处理并写明理由**（我方无电力电子设备制造与调度执行权），**但记录"若未来承接站端聚合/调度类业务需重新评估"** —— 这是留接口而不是留空
- [ ] **等保 / 关基基线差距清单**：按安全域"合规基线"采集线产出**首版清单**，范围限定为对外站点 + 监控平台 + 交易接口三类，**不追求一次覆盖全资产**
- [ ] **信创观察项归档**：均压电阻 / 关键矿产 / 供应链转向三条进长期观察台账，**每条标注证据强度**（论文未核实 / 与产业现状有张力 / 已多轮鉴定）
- [ ] **隐私保护方向**：先补"我方数据清单"（采集哪些字段、存多久、给谁）—— **这是待核实动作，不是合规结论**
- [ ] **季度复检机制**：对照表纳入季度安全复检，攻击面实证变化（如 WAF 新观测）触发对照表更新

### 不做什么（划边界）

- ❌ **不做任何产品功能改造**（不新增工控协议模块、不做隐私计算、不做 AI 防御）—— 那是产品线级动作，待材料积累后另立项
- ❌ **不做渗透测试 / 不做主动攻击** —— 本对照表基于已有观测与公开披露，不新增攻击行为
- ❌ **不改 WAF 现有黑名单策略**（另议）
- ❌ **不把院刊综述的极端情景案例当证据**（伊比利亚停电归因与 ENTSO-E 官方结论相反；Moss Landing 单位与疏散人数有误）—— 对照表只取其**手法分类**，不取其案例数据
- ❌ **不作"卡脖子"结论**（均压电阻一条我方核查标注与产业现状有张力）
- ❌ **不声称等保达标** —— 基线差距清单是差距，不是结论

## 4. 验收标准

- [ ] 对照表交付，**≥6 类攻击手法 × 4 状态标注**（已覆盖 / 部分覆盖 / 未覆盖 / 不适用）齐全
- [ ] **每一行都挂了一条证据链接** —— 无证据的行不算完成（抽查 3 行能点开并回溯到原始报告 / 规则 / 产物条目）
- [ ] 每个"部分覆盖 / 未覆盖"行都有**可验证的最小补强动作**（写成一句"要做什么 + 完成标准"，不是"加强防护"）
- [ ] 补强动作与 [P0 暴露面专项自查](remediation-exposureHygiene-20261112.md) **无重复立项**，无孤儿动作
- [ ] "物理层攻击（EMP）"行标注 **不适用 + 理由 + 重新评估触发条件**
- [ ] 等保/关基基线差距清单**首版交付**，范围覆盖对外站点 + 监控平台 + 交易接口三类，**每条差距有责任方占位**（责任人仍待指派，不臆断）
- [ ] 信创观察项三条均标注**证据强度**，且未出现"卡脖子"结论
- [ ] 隐私方向交付**数据清单模板 + 已填字段的当前状态说明**（未填部分明确写"待核实"，不猜）
- [ ] 文档内**无产品特性级断言**（不出现具体产品的功能名 / 特性描述 / 应用场景描述）

## 6. 风险与依赖

- **依赖**：内部 WAF 巡检报告可继续获取（`waf-inspection-report-latest.md`）—— 对照表的证据链接大量指向它，报告断供则证据链断
- **依赖**：安全域"合规基线"采集线（等保 2.0 / 关基保护 / 数据安全法）需先有基线版本 —— 首版差距清单的基线来源需确认
- **风险**：手法表可能退化成"抄论文清单"而没有我方判定 —— **验收强制每行挂证据链接**，无证据即不通过
- **风险**：物理层攻击行若简单写"不适用"，将来承接站端业务时会漏掉 —— 已用"重新评估触发条件"留接口
- **风险**：我方现状多处不可查（等保定级现状、数据清单、BOM）—— **一律写"待核实"，不臆断**；对照表允许有"待核实"状态，但不允许有"想当然"
- **来源情报的偏差已影响本产物动作**：院刊综述 §二 核出极端情景引证存在归因错误（伊比利亚停电）、单位错误（Moss Landing `MW·h`）、人数夸大。
  **本产物只采用其手法分类与防御框架，不引用任何案例数据与量级数字** —— 手法的成立性由我方观测与公开披露独立支撑。
