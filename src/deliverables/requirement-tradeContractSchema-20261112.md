# 交易合约数据结构扩展（多年期 / 跨省 / 辅助服务品种）

> 类型：**需求变更** · 优先级：P1 · 责任人：\<待指派\>
> 来源情报：[发改委/能源局促进新能源消纳和调控指导意见](../policy/ndrcNewEnergyConsumptionGuidance-2026.md)
> 提出日期：2026-11-12 · 评审状态：待评审

## 1. 背景与证据

同一份 2026-11-10 指导意见提出三条直接改变交易数据结构的要求：

> "支持分布式新能源、储能、虚拟电厂等新型主体通过聚合、直接交易等模式参与电力市场"
> "**研究推动新能源、用户等主体参与跨省跨区电力市场直接交易**"
> "通过推广**多年期购电协议**，帮助新能源企业锁定长期消纳水平"
> "**缩短中长期市场交易周期**，便于新能源合约持仓调整"
> "加快现货和辅助服务市场建设"

**现状**：我方交易合约模型基于「单市场 + 固定期限 + 电量单一品种」三个假设。政策要求全部打破。

**关键风险**：如果合约模型不扩字段，**跨省跨区直交易与多年期 PPA 这两类新业务根本无法在我们的系统里落账** —— 不是功能少，是数据模型不支持。这是硬约束，不是可选项。

## 2. 影响面

| 受影响系统/产品线 | 影响点 | 现状 |
|---|---|---|
| PTM 现货交易平台 | 合约主数据结构 | 单市场、单期限、单品种 |
| 兆瓦快链 | 持仓管理、敞口监控 | 无跨省维度 |
| 品能者托管 | 分布式聚合交易的合约承接 | 无法承接聚合合约 |

## 3. 动作

### 做什么

**合约主表扩展**

- [ ] 新增 `marketScope` 字段（省级 / 跨省 / 跨区），取值来自可维护的区划字典
- [ ] 新增 `contractTermType` 字段（年度 / 多年期），并新增合约期限明细子表（起止时间、各年量价）
- [ ] 品种从单值改为**明细子表**（电能量 / 现货 / 辅助服务 / 绿证），每品种独立量价与结算规则标识
- [ ] 新增 `participantType`（发电 / 用户 / 储能 / 虚拟电厂 / 聚合商）
- [ ] 新增 `aggregationMode`（直接交易 / 聚合交易）+ 聚合体标识

**结算与持仓**

- [ ] 结算单元支持跨省跨区结算口径
- [ ] 持仓管理支持按合约期限分段（多年期合约的不同年度段可分别调整）
- [ ] 敞口监控支持按区划维度聚合

### 不做什么（划边界）

- ❌ 不做具体的交易策略/算法（策略是 PTM 的业务能力，不属本次结构变更）
- ❌ 不改历史合约数据（旧数据按默认值回填，缺失字段置为兼容值）
- ❌ 不做绿证/碳资产的独立结算模块（另立需求，见下）

### 兼容策略（重要）

存量合约数据不能因为结构变更而不可用：

- 旧数据按映射回填：`marketScope=province`，`contractTermType=annual`，品种明细仅电能量
- 所有新增字段设默认值 + 允许 null，null 走"按旧逻辑处理"的兼容分支
- 提供一次性回填脚本 + 回填后校验报告

## 4. 验收标准

- [ ] 新合约可完整表达：多年期 + 跨省 + 多品种（含辅助服务）的组合
- [ ] 存量合约在新模型下可正常查询、持仓计算、结算，**结果与改造前一致**（回归对比 100% 一致）
- [ ] 区划字典与辅助服务品种字典可维护（不需改代码即可新增条目）
- [ ] 多年期合约的不同年度段可独立调整持仓，且持仓汇总正确
- [ ] 回填脚本可重复执行且幂等（第二次执行结果不变）

## 5. 排期

| 阶段 | 时间 | 产出 |
|---|---|---|
| 口径与字典定义 | 2 周 | 字段字典 + 区划字典 + 品种字典 + 映射规则 |
| 设计与评审 | 1 周 | 数据库变更方案 + API 兼容方案 |
| 开发 | 4 周 | 模型 + API + 回填脚本 |
| 上线 | 随 R2026.12（分两期：先只读双写，再切读写） | 双写验证报告 |

## 6. 风险与依赖

- **依赖**：跨省跨区交易的具体规则（结算口径、争议处理）尚未明确 → 字段设计需容忍规则未定，先留 `ruleRef` 扩展位
- **风险**：多年期合约的履约担保模型未同步扩展 → 本次只改结构，担保逻辑另立需求
- **风险**：改造面大，回滚困难 → 分两期上线，第一期只读双写
- **风险**：绿证/碳市场协同（"电—证—碳"）的环境价值结算，若本次不预留字段，后续必然二次改造 → 品种明细表预留 `environmentalValue` 扩展位
